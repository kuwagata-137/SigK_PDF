# SigK PDF

PDF の閲覧・ページ操作・結合・分割・変換・注釈を、1つの画面で行う Windows デスクトップアプリケーション。

**現在の状態: Phase 5「シェル統合と配布」の塊①（右クリックメニュー）を終えた（2026-09-25。PR #25 をマージ）。
2026-09-28 に、Phase 5 塊②の前へ Phase 4B「注釈の拡充」を入れた。塊①は 2 本に分け（2026-09-29）、塊①-a（編集モードの組み替えと読み戻しの口）と塊①-b（書き込みの見た目の設定）を PR #27・#28 でマージした（2026-09-30）。塊②（大きさと向き）を PR #30 でマージした（2026-10-01）。塊③は 2 本に分け、塊③-a（選択と複数選択）と塊③-b（ハンドと右ボタン）を PR #31・#32 でマージした（2026-10-01）。2026-10-02 に塊④（テキストと吹き出し）に着手し、塊④-a（テキストの書式）を実装した（PR はユーザーの指示待ち）。
読む・並べ替える・保存する・結合する・分割する・見開きで読む・
画像（JPEG・PNG・BMP・GIF・TIFF）を PDF にする・PDF のページを PNG／JPEG にする・
文字にハイライト・下線・取り消し線を付ける・紙の好きな位置に日本語のテキストを置く（文字の大きさ・太字・斜体・塗り・枠線、12 字の折り返しと幅のつまみ）・矩形・楕円・直線・矢印を描く・
ペンでなぞる・付箋（ノート）を置いてコメントを書く・文書内の注釈を一覧で辿る・文字や画像の透かしを重ねる・
注釈をページへ焼き込む（フラット化）までが動き、常用している。**

PDF をダイアログ・ドラッグ＆ドロップ・最近使ったファイル・エクスプローラーのダブルクリックから
開き、タブで並べて、連続スクロール・ズーム・ページ移動で読める。単ページと見開き（2ページを
横に並べる）を切り替えられ、選択は次回起動にも残る。サイドパネルのサムネイルで
今いる場所が分かり、文字を選んでコピーできる。文書内をテキスト検索でき、紙にも印刷できる。
文書情報も見られる。パスワード付きの PDF も開ける。

ページモードでは、サムネイルをドラッグして並べ替え、90度単位で回転し、削除できる。
Ctrl / Shift クリックで複数のページを選べ、Ctrl+Z で元に戻せる。選んだページを別ファイルへ
抽出でき、画像や別の PDF のページを差し込める。Ctrl+S で上書き保存（元ファイルは `.bak` に
退避）、Ctrl+Shift+S で名前を付けて保存できる。重い保存はワーカーで回り、進捗の帯から中止できる。

ツールモードでは、複数の PDF を並べ替え・ページ範囲を指定して1つに結合でき、1つの PDF を
ページ数・位置・範囲で複数に分割できる（連番かページ番号のファイル名）。JPEG・PNG・BMP・GIF・TIFF を
用紙（A4・A3・B5・レター・画像サイズ）・向き・余白を選んで PDF にでき、1つにまとめるか
画像ごとに分けるかを選べる。PDF のページ（すべてか範囲）を PNG か JPEG に 72／150／300dpi で
書き出せる。出力先に同名があれば上書き・別名・中止の3択で確認する。「透かし」では、1つの PDF の全ページか
指定したページに、日本語の文字か画像（PNG・JPEG）を重ねられる。大きさ（小・中・大）・色・不透明度・向き（斜め・水平）・
9 か所の位置を選び、右のプレビューで見え方を確かめてから書き出す。文字は字形の輪郭で描くので、書き出したファイルで
透かしの文字が検索やコピーに混ざらない。「フラット化」では、画面に見えている注釈をページの内容として焼き込める
（焼き込む件数・残すもの・失うものを確かめてから実行する）。どちらも出力先は実行時の保存ダイアログで選び、
結果は新しいタブで開く。元のファイルは変えない。

注釈モード（画面の呼び名は「編集」。紙に付けたもの 1 つひとつは「書き込み」）では、ツールバーの下に道具の段が出る
（ハイライト・下線・取り消し線｜テキスト｜矢印・直線・四角・丸｜ペン・ノート）。文字をなぞってハイライト・下線・
取り消し線を付けられる（先に文字を選んでから道具を押しても付く）。色はプリセットから選び、押して選んだ書き込みを
Delete で消し、Ctrl+Z で戻せる。保存すると PDF 標準の注釈（外観付き）として書かれ、他のビューアでも見える。ほかのアプリで
付けたハイライト・下線・取り消し線も消したり色を変えたりでき、印刷には未保存の書き込みも映る。「テキスト」の道具で紙の
好きな位置を押すと入力欄が開き、日本語の文字を置ける（同梱フォントで書くので他のビューアでも同じ字で見える）。置いた文字は
ダブルクリックで直し、掴んで動かし、文字の大きさをプリセットから選べる。「矢印」「直線」「四角」「丸」の道具で紙の上を
ドラッグすると描け（Shift で正方形・正円・45° 刻み）、「ペン」でなぞると手描きの線が引ける。色（パレットか任意の色）と線の太さ
（1〜40pt）、四角・丸の塗りと線種（実線・破線・雲形）を選べ、描いたものは掴んで動かし、Delete で消せる。選んだ四角・丸は 8 点の
つまみで大きさを、上の丸いつまみか右パネルの「回転」の行で向きを変えられ（Shift で縦と横の比を保つ・15° 刻み）、直線・矢印は
両端のつまみで向きと長さを変えられる（Shift で横か縦にだけ動く）。回した図形は他のビューアでも回ったまま見える。他のアプリで付けた
四角・丸・ペンも読み込んで直せ、他のアプリで回した四角・丸も回ったまま直せる。
「ノート」の道具で紙を押すと付箋が置け、右のパネルの「本文」にコメントを書ける（色 4 色・作成者付き。付箋は倍率を変えても
回転したページでも同じ大きさ・上向き）。図形・ペン・テキスト・ノートは不透明度も選べ、ファイルに書かれた不透明度も読み戻して
そのまま直せる。左のサイドパネルは既定でサムネイルで、見出しの［サムネイル｜注釈一覧］で文書内の書き込みの一覧に替えられ、
行を押すと該当箇所へ飛ぶ。他のアプリで付けた付箋も読み込んで直せ、直線・スタンプや、ゆがめて回した図形など、まだ同じ見た目に
直せないものも一覧に「表示のみ」で並んで消せる。
保存に成功すると保存先を開き直すので、保存後は Ctrl+Z で保存前へ戻れない。

インストーラーで入れると、エクスプローラーの右クリックメニューからも使える。PDF を右クリックすると「SigK PDF」の下に
「SigK PDF で開く」「選択した PDF を結合」「PDF を分割」が、画像（PNG・JPEG・BMP・GIF・TIFF）では「PDF に変換（SigK PDF）」が
出る。何個選んでも項目が出て、窓は 1 つのまま、結合と画像→PDF の一覧にファイル名の順で並ぶ。Windows 11 では
「その他のオプションを確認」の中にある。アンインストールすると項目は消え、設定は残る。

```bash
npm install && npm test && npm start
```

## これは何か

無償の PDF ユーティリティは、機能ごとに画面が独立している。開いて、処理して、閉じる。統合型の商用ソフトは、1枚の文書を開いたまま閲覧・編集・書き出しを行き来できるが、価格と機能の重さが見合わないことがある。

SigK PDF は、**統合型の操作感で、機能の範囲は絞る**。文書を開いたまま作業を続けられ、扱う機能は日常業務で使うものに限る。すべての処理をローカルで行い、ファイルを外部へ送らない。

詳しい位置づけは [`docs/01_製品要件定義.md`](docs/01_製品要件定義.md) に記す。

## 主な機能（第1版の予定）

| 分類 | 内容 |
|---|---|
| 閲覧 | 連続スクロール表示、ズーム、サムネイル、テキスト検索・選択、印刷 |
| ページ操作 | 並べ替え、回転、削除、抽出、挿入、元に戻す／やり直し |
| 結合・分割 | 複数 PDF の結合、ページ数・位置・範囲による分割 |
| 変換 | 画像 → PDF、PDF → 画像 |
| 注釈 | ハイライト、下線、取り消し線、テキスト、図形、フリーハンド、ノート、フラット化（注釈の焼き込み）。色はパレットか任意の色、四角・丸の塗りつぶしと線なし、線種（実線・破線・雲形）、線の太さ 1〜40pt、不透明度 10〜100%（Phase 4B 塊①）。四角・丸の 8 点のつまみと回転、直線・矢印の端の移動（Phase 4B 塊②）。Phase 4B でこのあと、複数選択と複製、テキストの書式、吹き出し、×印・多角形・マーカー・消しゴム、モザイク、トリミングを足す |
| 透かし | テキスト透かし、画像透かし |
| シェル統合 | エクスプローラーの右クリックから「開く」「結合」「分割」「PDF に変換」 |

圧縮・OCR・パスワード保護・墨消し・フォーム入力は第2版以降で検討する。ページ内の既存テキストの直接編集と、レイアウトを保った Office 形式への変換は実装しない。

## 動作環境

- Windows 10 (21H2 以降) / Windows 11、x64
- NSIS 形式のセットアップインストーラーで配布。管理者権限は不要
- ネットワーク接続は不要

## 技術構成

Electron ＋ 素の HTML / CSS / JavaScript。ビルドステップを置かない。同一作者の [CheckListMaker](https://github.com/kuwagata-137/CheckListMaker) と構成を揃えている。

| 用途 | 採用 |
|---|---|
| PDF の描画 | pdfjs-dist (Apache-2.0) |
| PDF の生成・編集 | pdf-lib (MIT) |
| TIFF・GIF の伸長 | utif (MIT) ＋ omggif (MIT)。BMP は自作 |
| 日本語フォント埋め込み | @pdf-lib/fontkit (MIT) ＋ Noto Sans JP (SIL OFL 1.1) |
| パッケージング | electron-builder → NSIS |
| テスト | `node --test` ＋ jsdom |

## 商標について

本プロジェクトは独立して開発されており、いかなる企業とも提携・提携表示・後援関係にない。PDF は ISO 32000-1 として標準化された公開仕様であり、本アプリはその範囲で読み書きを行う。
