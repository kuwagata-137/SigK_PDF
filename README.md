# SigK PDF

PDF の閲覧・ページ操作・結合・分割・変換・注釈を、1つの画面で行う Windows デスクトップアプリケーション。

**現在の状態: Phase 4「注釈・テキスト・透かし」の塊③（図形・フリーハンド）まで完了した（2026-09-17。
PR はユーザーの指示待ち）。読む・並べ替える・保存する・結合する・分割する・見開きで読む・
画像（JPEG・PNG・BMP・GIF・TIFF）を PDF にする・PDF のページを PNG／JPEG にする・文字にハイライト・下線・
取り消し線を付ける・紙の好きな位置に日本語のテキストを置く・矩形・楕円・直線・矢印を描く・ペンでなぞるまでが動き、
常用している。次は塊④（ノート注釈＋注釈一覧）。**

PDF をダイアログ・ドラッグ＆ドロップ・最近使ったファイル・エクスプローラーのダブルクリックから
開き、タブで並べて、連続スクロール・ズーム・ページ移動で読める。単ページと見開き（2ページを
横に並べる）を切り替えられ、選択は次回起動にも残る。サイドパネルのサムネイルで
今いる場所が分かり、文字を選んでコピーできる。文書内をテキスト検索でき、紙にも印刷できる。
文書情報も見られる。パスワード付きの PDF も開ける。

ページモードでは、サムネイルをドラッグして並べ替え、90度単位で回転し、削除できる。
Ctrl / Shift クリックで複数のページを選べ、Ctrl+Z で元に戻せる。選んだページを別ファイルへ
抽出でき、画像や別の PDF のページを差し込める。Ctrl+S で上書き保存（元ファイルは `.bak` に
退避）、Ctrl+Shift+S で名前を付けて保存できる。重い保存はワーカーで回り、進捗の帯から中止できる。

ツールモードでは、複数の PDF を並べ替え・ページ範囲を指定して1つに結合でき、1つの PDF を
ページ数・位置・範囲で複数に分割できる（連番かページ番号のファイル名）。JPEG・PNG・BMP・GIF・TIFF を
用紙（A4・A3・B5・レター・画像サイズ）・向き・余白を選んで PDF にでき、1つにまとめるか
画像ごとに分けるかを選べる。PDF のページ（すべてか範囲）を PNG か JPEG に 72／150／300dpi で
書き出せる。出力先に同名があれば上書き・別名・中止の3択で確認する。

注釈モードでは、文字をなぞってハイライト・下線・取り消し線を付けられる（先に文字を選んでから道具を
押しても付く）。色はプリセットから選び、押して選んだ注釈を Delete で消し、Ctrl+Z で戻せる。保存すると
PDF 標準の注釈（外観付き）として書かれ、他のビューアでも見える。ほかのアプリで付けたハイライト・下線・
取り消し線も消したり色を変えたりでき、印刷には未保存の注釈も映る。「テキスト」の道具で紙の好きな位置を押すと
入力欄が開き、日本語の文字を置ける（同梱フォントで書くので他のビューアでも同じ字で見える）。置いた文字は
ダブルクリックで直し、掴んで動かし、文字の大きさをプリセットから選べる。「図形」の道具で紙の上をドラッグすると
矩形・楕円・直線・矢印が描け（種類は右のパネルで切り替え、Shift で正方形・正円・45° 刻み）、「ペン」でなぞると
手描きの線が引ける。色（赤・青・緑・黒）と線の太さ（1〜8pt）を選べ、描いたものは掴んで動かし、Delete で消せる。
他のアプリで付けた矩形・楕円・ペンも読み込んで直せる。保存に成功すると保存先を開き直すので、
保存後は Ctrl+Z で保存前へ戻れない。

ノート・注釈一覧・透かし、右クリックメニューはまだ無い（`docs/05_開発ロードマップ.md` Phase 4 塊④以降）。

```bash
npm install && npm test && npm start
```

## これは何か

無償の PDF ユーティリティは、機能ごとに画面が独立している。開いて、処理して、閉じる。統合型の商用ソフトは、1枚の文書を開いたまま閲覧・編集・書き出しを行き来できるが、価格と機能の重さが見合わないことがある。

SigK PDF は、**統合型の操作感で、機能の範囲は絞る**。文書を開いたまま作業を続けられ、扱う機能は日常業務で使うものに限る。すべての処理をローカルで行い、ファイルを外部へ送らない。

詳しい位置づけは [`docs/01_製品要件定義.md`](docs/01_製品要件定義.md) に記す。

## 主な機能（第1版の予定）

| 分類 | 内容 |
|---|---|
| 閲覧 | 連続スクロール表示、ズーム、サムネイル、テキスト検索・選択、印刷 |
| ページ操作 | 並べ替え、回転、削除、抽出、挿入、元に戻す／やり直し |
| 結合・分割 | 複数 PDF の結合、ページ数・位置・範囲による分割 |
| 変換 | 画像 → PDF、PDF → 画像 |
| 注釈 | ハイライト、下線、取り消し線、テキスト、図形、フリーハンド、ノート |
| 透かし | テキスト透かし、画像透かし |
| シェル統合 | エクスプローラーの右クリックから「開く」「結合」「分割」「PDF に変換」 |

圧縮・OCR・パスワード保護・墨消し・フォーム入力は第2版以降で検討する。ページ内の既存テキストの直接編集と、レイアウトを保った Office 形式への変換は実装しない。

## 動作環境

- Windows 10 (21H2 以降) / Windows 11、x64
- NSIS 形式のセットアップインストーラーで配布。管理者権限は不要
- ネットワーク接続は不要

## 技術構成

Electron ＋ 素の HTML / CSS / JavaScript。ビルドステップを置かない。同一作者の [CheckListMaker](https://github.com/kuwagata-137/CheckListMaker) と構成を揃えている。

| 用途 | 採用 |
|---|---|
| PDF の描画 | pdfjs-dist (Apache-2.0) |
| PDF の生成・編集 | pdf-lib (MIT) |
| TIFF・GIF の伸長 | utif (MIT) ＋ omggif (MIT)。BMP は自作 |
| 日本語フォント埋め込み | @pdf-lib/fontkit (MIT) ＋ Noto Sans JP (SIL OFL 1.1) |
| パッケージング | electron-builder → NSIS |
| テスト | `node --test` ＋ jsdom |

## 商標について

本プロジェクトは独立して開発されており、いかなる企業とも提携・提携表示・後援関係にない。PDF は ISO 32000-1 として標準化された公開仕様であり、本アプリはその範囲で読み書きを行う。
