## 目的

編集モードのテキストの書き込みに、**文字の大きさ 8〜200pt、太字と斜体、塗りと枠線を付けられ、全角 12 字の幅で折り返し、
左右のつまみで幅を変えられる**ようにする（F-05-14）。画面・入力中・印刷・保存した PDF で、字の形と改行の位置を同じにする。
保存は PDF の決まりの欄（`/DA`・`/DS`・`/C`・`/BS`・外観）だけで行い、開き直しても同じ見た目のまま直せる。

塊④は 2 本に割った（決定56）。後半の ④-b（テキストの回転と吹き出し）は別のセッションで行い、ここでは論点の答えと事前調査の
結果だけを書き残す（`~/.claude/plans/phase-4b-4b-handoff.md` に引き継ぐ）。

## 含めるもの / 含めないもの

| 含めるもの | 含めないもの |
|---|---|
| 文字の大きさ 8〜200pt（数値の欄＋よく使う大きさの一覧。0.5 刻み） | テキストの回転（④-b） |
| 太字（Bold の書体を同梱）・斜体（傾けて出す） | 吹き出し（④-b。道具の段のボタンも ④-b で足す） |
| 塗り（パレット・なし）、枠線（色・なし・太さ 1〜40pt） | 枠線の線種（破線・雲形）。テキストの枠線は実線だけ |
| 全角 12 字での折り返し（短ければ箱が縮む）、左右の幅のつまみ（固定幅） | 禁則処理・英数字の語をまとめる折り返し（論点3） |
| 複数選択で文字の大きさ・書式・枠線をまとめて変える（テキストにだけ効く） | 他のアプリの FreeText を直せるようにすること（論点2。表示のみのまま） |
| 次に付ける値（太字・斜体・塗り・枠線・枠線の太さ）を覚える | 太字・斜体のキーボードの近道（Ctrl+B など。起草者の判断） |
| 半透明の塗り・枠線・文字の重なりを濃くしない（透明グループ） | 1 つのテキストの中で書式を混ぜること（文字ごとの太字など。`/RC`） |
| 今までのテキストは今のまま（折り返さない）。幅のつまみや書式を付けると新しい形に移る | 保存のたびにフォントのサブセットが 1 組増える既知の限界（決定35 ⑤） |

## 事前調査（2026-10-02・Windows 11 実機・Chrome 152 の Browser パネル・Electron 44・pdf.js 6.3.289・pdf-lib 1.17.1・scratchpad の検体のみ）

試作は scratchpad の使い捨て（Node で pdf-lib＋fontkit を回して検体を作るもの、Browser パネルの pdf.js で描いて画素を比べるもの、
本物のアプリの隠した窓に部品を差し込んで見本を撮るもの）。④-b のための F・G の試作は引き継ぎ文書へ写した。

### A. CheckListMaker のテキストと吹き出し（`kuwagata-137/CheckListMaker` ce37cc6 の `index.html` を読んだ）

- 文字の大きさは数値の欄＋▾の一覧（8〜200・刻み 1、一覧 10〜200 の 16 段）。太字・斜体は canvas の font に付けるだけ。
- 折り返しは「大きさ×12」の幅で 1 字ずつ（禁則なし）、明示の改行は残す。幅を手で変えていなければ箱は最長行に縮む。
- 幅のつまみはテキストの左右の辺の中点に 2 つ。引くと固定幅になり、以後の高さは文字量で決まる。最小幅は 1 字。
- 大きさを変えたとき、固定幅なら幅を保ち、そうでなければ大きさ×12 で組み直す。
- 入力欄の幅は行組みの幅＋4px だけにする（広いと入力中だけ 1 字多く入り、確定後と折り返しがずれる）。
- 吹き出し・回転は ④-b の引き継ぎ文書に書いた。

### B. 太字の出し方 — Bold の書体を同梱する。斜体は傾き 0.25

- Bold の書体: Google Fonts v56 の静的 TTF `NotoSansJP-Bold.ttf`（5,468,188 バイト。同梱の Regular と同じ版 2.004-H2、
  hhea 1160/−288、グリフ 17,103、字の集合も同じ。全角の字幅は同じで、英数字は 5.5% 広い。OFL、埋め込み可）。ユーザーの許可を
  得てから取ってきた（2026-10-02）。いまの一覧 API は v57 を返すので、版をそろえるために v56 の URL から取った。
- 検体（「鬱議響驚 あア Ab1」を 8〜200pt で）を pdf.js で描くと、**線を足す擬似太字（`2 Tr`＋線 1/30em）は画数の多い漢字の
  すき間が埋まる**（200pt で「鬱」がつぶれる。8pt の倍率 100% でも黒い塊になる）。Bold の書体は形を保つ。
- 画面（Chromium の canvas）と pdf.js の画素の差（差 32 を超える画素 ÷ 字の画素）: 標準 0%・Bold の書体 0%・擬似太字 0%・
  **斜体は `Tm` の傾き 0.25 が Chromium の擬似斜体（`font-style: italic`）と 0%**、0.2 は 34〜42%。
- 埋め込みの時間は Regular だけ 44ms、Bold も 41ms（新しいプロセス）。見本 `screenshots/phase4b-4-bold.png`。

### C・D. 欄の書き先（規格と他の実装。Web とリポジトリの `vendor/pdf.worker.mjs`）

- 規格 1.7 表174: FreeText の固有の欄は `/DA`（必須）・`/Q`・`/RC`・`/DS`・`/CL`・`/IT`・`/BE`・`/RD`・`/BS`・`/LE`。`/IC` は無い
  （2.0 でも無い）。外観があれば外観が優先。`/BS` も `/Border` も無いと 1pt の実線の枠とみなす決まり。
- PDFBox・MuPDF・Acrobat の説明は同じ割り当て: **塗りは `/C`、枠線の色は `/DA` の色、文字の色は `/DS` の `color`（無ければ
  `/DA` の色）、枠線の太さは `/BS /W`、大きさは `/DA` の `Tf`**。外観を作り直すアプリは `/DA` の書体名を AcroForm の `/DR` から
  引くので、`/SigKJP` の日本語は描けない（今と同じ。外観がある限り見た目は保たれる）。
- pdf.js は `/C` を data.color に入れるだけで、`/DS`・`/RC` を読まない。**外観があれば、外観の最初の文字の命令までの `Tf` と塗りの
  色で fontSize・fontColor を上書きする**（`vendor/pdf.worker.mjs:38326-38420`・`55700-55707`）。pdf.js で編集すると `/DA` を
  `/Helv` に、`/RC` を消して文字だけの外観を作り直す。

### E. 画面と保存で折り返しをずらさない方法

- 純関数（1 字ずつ詰め、送り幅の和が幅を超えたら改行。行に最低 1 字。改行は残す）と、入力欄と同じ CSS の要素の行を、文 200〜400 本 ×
  大きさ 8〜200 × 幅 × 倍率 25〜400%（9 段）で比べた。
- 既定の CSS では 1,800 中 808 がずれる（Chromium の `text-spacing-trim` の既定が「：「」のような約物の並びを詰める）。
  **`white-space: break-spaces; line-break: anywhere; word-break: break-all; overflow-wrap: anywhere; font-kerning: none;
  font-variant-ligatures: none; text-spacing-trim: space-all`** で 3/1,800。`pre-wrap` は行末の空白がぶら下がるので 75/1,800。
- 残りは境界（行が幅を 0.05pt 超える字を、入力欄は入れてしまう）。**入力欄の幅を「最長行」と「次の字を足した行の最小」の
  真ん中に置く**と 0/3,600（素の幅では 18/3,600）。
- 送り幅: kerning を切った canvas の値は fontkit の字幅（hmtx）と 292 字で一致（`"` `'` だけ 0.001em 違う。害は無い）。大きさに
  比例する。**pdf-lib の `encodeText` は合字を作る**（「office fifty」で幅が 0.084pt 違う）ので、保存側も合字を切る。

### F・G. 回転と吹き出し（④-b 用。引き継ぎ文書に詳しく書いた）

### J. 半透明の塗り・枠線・文字の重ね方

## 確定事項

### A. 書き込みの持ち方（`renderer/annotation-entry.js`・`annotation-entry-rules.js`・新 `renderer/free-text-style.js`）

1. テキストの entry に次の欄を足す（無い欄は既定の値として扱い、既定の値は持たない）:
   - `width` … 折り返しの幅。**無い＝今までのテキスト（折り返さない）**、`'auto'`＝自動（全角 12 字。確定事項C2）、正の数＝固定（中身の幅 pt）
   - `bold: true`・`italic: true`（false のときは持たない）
   - `fill` … 塗り（`'#rrggbb'` か null）
   - `borderColor` … 枠線の色（`'#rrggbb'` か null）。`borderWidth` … 枠線の太さ（pt。正の数。枠線があるときだけ意味を持つ）
2. **新しい形**（`width` を持つ）と**今までの形**（持たない）を分ける。今までの形に、幅のつまみ・太字・斜体・塗り・枠線のどれかを
   当てると、新しい形に移る（`width` は今の最長行の幅＝固定。行の並びは変わらない）。文字の大きさ・色・不透明度だけなら今までの形のまま。
3. 文字の大きさは 8〜200 の 0.5 刻み（`annotation-presets.js` の `isFontSize` を範囲と刻みの判定に改める）。今までの 14 段の一覧は
   「よく使う大きさ」の一覧（8・9・10・10.5・11・12・14・16・18・20・24・28・36・48・72・96・144・200）になる。読み込んだ大きさは
   範囲の外でもそのまま持つ（今までどおり）。
4. 書き換えられる欄（`PATCH_FIELDS`）に `width`・`bold`・`italic`・`borderColor`・`borderWidth` を足し、`fill` をテキストにも許す。

### B. 箱の組み立て（新 `renderer/free-text-layout.js`。純関数）

1. 箱 ＝ 中身（行の並び）＋余白。行送りは 1.25em、ベースラインは行の上端から 1.061em（今までどおり）。
2. 余白: 塗りも枠線も無いときは 2pt（今までどおり）。**塗りか枠線があるときは max(2, 大きさ×0.3 を四捨五入) ＋枠線の太さ**
   （CheckListMaker と同じく、飾りがあるときだけ広げる。枠線は箱の内側に描く）。
3. **斜体は右に 0.25em、左に 0.08em を足す**（傾けた字の上の端と下の端が箱の外へはみ出さないように。外観の `/BBox` は中身を切る）。
4. 箱の幅 ＝ 中身の幅＋左右の余白（＋斜体の分）。中身の幅は、固定なら `width`、自動と今までの形なら最長行の幅。高さ ＝ 行数×1.25em＋上下の余白。
5. **飾り（塗り・枠線・太さ）・大きさ・斜体を変えて余白が変わっても、中身の左上（文字の位置）は動かさない**。箱は外へ広がる（起草者の判断）。
6. 字の送り幅は、kerning を切った canvas で 1000px で測った値を字ごとに覚えて足す（合字・詰めは使わない。事前調査 E）。太字は Bold の書体で測る。

### C. 折り返し（新 `renderer/free-text-wrap.js`。純関数）

1. 1 字ずつ詰める（論点3）。送り幅の和が幅を超える字から次の行へ送る。行に最低 1 字。明示の改行（Shift＋Enter・Enter）は残す。
   空白も字として幅を持ち、行末でもぶら下げない。
2. **自動の幅 ＝ min(大きさ×12, 紙の幅 − 余白×2 − 斜体の分)**（論点4）。紙の幅は、文字の向き（置いたときの表示の回転）に沿った
   ページの長さ（今の表示の大きさ。トリミングされていればその大きさ）。押した位置にはよらない。下限は 1 字（大きさ）。
3. 固定の幅の下限も 1 字（大きさ）。上限は無い。
4. 大きさを変えたとき、固定の幅は保ち（下限を下回れば下限）、自動は新しい大きさで組み直す（論点8）。
5. 今までの形は折り返さない（明示の改行だけ）。

### D. 画面に描く（`renderer/free-text-shape.js`・`annotation-layer.js`）

1. SVG: `<g>` に塗りの `<rect>`・枠線の `<rect>`（箱の内側に線の太さの半分だけ入れる）・行ごとの `<text>`。`font-weight: 700`（Bold の
   `@font-face`）・`font-style: italic`、CSS は事前調査 E の 7 つ（`.annot-layer .free-text text`）。今までの形のテキストにも同じ CSS を当てる。
2. 不透明度 1 未満は `<g opacity>`（今までどおり。塗り・枠線・文字が 1 枚として透ける）。
3. 印刷の canvas: `ctx.fontKerning = 'none'`、`textRendering = 'optimizeSpeed'`（合字を切る）。不透明度 1 未満は図形と同じく
   別の層（`print-layer.js`）に描いてから重ねる。
4. `shell.css` に `@font-face { font-family: 'SigK Noto Sans JP'; src: url('../assets/fonts/NotoSansJP-Bold.ttf'); font-weight: 700 }` を足す。
   `ensureLoaded` は Regular と Bold の両方を待つ。

### E. 入力欄（`renderer/free-text-editor.js`）

1. 新しい形: `wrap='soft'` と事前調査 E の CSS。**幅は「最長行」と「次の字を足した行の最小」の真ん中**（折り返す行が無ければ中身の幅）を
   入力のたびに求め直す（IME の変換中も）。高さは行数×行送り（今までどおり `scrollHeight` で補う）。
2. 余白・太字・斜体・文字の色を入力欄にも当てる。塗りがあれば入力欄の地をその色にする（枠線は入力欄の破線の枠の代わりに描かない。起草者の判断）。
3. 今までの形は今のまま（`wrap='off'`、広がる）。
4. 入力中は書式を変えられない（右パネルの書式の行は効くが、入力欄を確定してから当てる。今の色と同じ扱い）。

### F. 幅のつまみ（新 `renderer/free-text-handles.js`・`free-text-resize.js`。モック `phase4b-4-wrap.png` ②④）

1. 自前のテキスト（表示のみでないもの）を 1 件選ぶと、枠の左右の辺の中点に白い丸のつまみ（今のつまみと同じ半径 5px）が出る。
   今までの形のテキストにも出す（引くと固定幅の新しい形に移る。確定事項A2）。
2. 左右は文字の向き（置いたときの表示）で決める。引いたつまみの反対側の辺は動かない。カーソルは `ew-resize`（今の向きに合わせる）。
3. 引いている間は下見（新しい幅で折り返した行と箱）。離すと 1 世代積む。Esc で取りやめ。左＋右での取りやめも今のつまみと同じ。
4. 中身の幅は 0.01pt に丸める（開き直したときに同じ幅を求め直せるように）。
5. 2 件以上を選んでいる間はつまみを出さない（今の決まり）。

### G. 右パネル（`renderer/annotation-props.js` ほか。モック `phase4b-4-props.png`・`-multi.png`）

1. テキストを選んだとき（と、テキストの道具を持っているとき）の並び: **種類・文字の色・文字の大きさ・書式・塗り・枠線・枠線の太さ・
   不透明度・ページ・本文**（論点6）。「枠線の太さ」は枠線があるときだけ出す。
2. 文字の大きさ: 数値の欄（8〜200、0.5 刻み。範囲の外と半端は近い値に丸めて受ける）と、右の ▼ で開くよく使う大きさの一覧（論点5）。
   数値の欄は Enter と欄を離れたときに当てる。
3. 書式: B と I のトグル（押している間は `.on`）。押すと 1 世代積む。
4. 塗り・枠線: 図形と同じチップとパレット（［なし］あり）。最初はどちらも「なし」。枠線の太さは 1〜40 のスライダーと数値欄（図形の線の太さと同じ部品・下見）。

6. 同じ欄を続けて変えたら 1 世代（決定53 ②。大きさ・太字・斜体・塗り・枠線の色・枠線の太さ）。

  幅より広い字だけの行（1 字の行）は、入力欄の幅の決め手にしない（DOM も 1 字で置くため）。
- **今までの形の行の幅の測り方（`measure`）も詰め（kerning）を切った**（画面の SVG・保存とそろえる）。
- **空の行は外観に描かない**（Tj を出さない。行送りは数える）。
- **テキストを選んだときのヒント**に「左右の白いつまみで幅を変えると、文字はその幅で折り返します。」を足した（図形のつまみの説明と同じ位置）。
- **固定の幅は、読み戻しの見分けが自動と見る値なら最長行より 0.02pt 広げる**（`free-text-metrics.js` の keepFixed。点検で直した 1 件目）。
- 起動確認の開き直しの確かめ（`reopen`）では、書き込みを作り直させるのに色の往復（`stroke:#000000,stroke:#222a35`）を使った。台本の `move:` は
  整数の画素でマウスを送るので、往復で 0.92pt ずつ位置がずれるため（アプリの不具合ではない）。

### 点検で直したこと

文書を書く前に、コードの変更を別のエージェントに点検してもらい、2 件見つかった。どちらもテストを先に足して赤を確かめてから直した（`e0a4055`）。

- **今までの形を太字などで新しい形に移したテキストが、保存して開き直すと「自動の幅」に変わっていた**（完了判定5 に反する）。移すときの固定の幅を
  最長の段落の幅ちょうどにしていたため、読み戻しの見分け（確定事項J3。最長行とほぼ同じで行も自動と同じなら自動）に当たっていた。短い見出しや
  ラベルで必ず起きる。固定の幅を決める 3 か所（今までの形から移す・幅のつまみ・大きさを上げて 1 字に広げる）で、見分けが自動と見る幅なら
  最長行より 0.02pt 広げるように直した（見分けの式は `imported-text-details.js` の judgeWidth を共有する）。仕様の決めごと（確定事項A2・J3・I）は変えていない。
- **文字の大きさの欄に打ちかけのまま別の書き込みを選ぶと、Enter か欄を離れたときに新しく選んだ書き込みへ当たっていた**（確定事項G2）。打ち始めたときの
  相手（選んでいる書き込みと道具）を覚え、相手が替われば欄をその相手の値に替えて、打ちかけの値は当てない。太さ・不透明度の数値欄（`props-range.js`。
  塊④より前の部品）にも同じ作りが残っているので、別の作業に切り出した。

### 既知の限界

- 保存のたびにフォントのサブセットが 1 組増える（決定35 ⑤から変わらない。太字の書体は太字のテキストがある保存だけ埋める。起動確認で 4 回保存すると 4 組）。
- 字の送り幅は canvas で測るので、フォントを読み終える前に測った幅は覚えない（`ensureLoaded` の後に測り直す）。画面の幅とワーカーの字幅の一致は
  事前調査 E の 292 字の照合による。IME の変換中の入力欄の折り返しは目で見ていない。
- 「固定の幅の最長行がちょうど幅いっぱい」のテキストを他のツールで書き換えたものは、自動と見なされることがある（決まりの欄に「自動」を書けないため。
  SigK が作る固定の幅は 0.02pt 広げて避けている）。
- 外観を作り直す他のビューア（PDFBox など）は `/SigKJP` の書体が無いので、日本語を描けないことがある（事前調査 C・D。保存した外観を使うビューアでは
