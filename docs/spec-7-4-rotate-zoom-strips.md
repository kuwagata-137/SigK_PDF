# 編集モードの回転ボタン・倍率 1000%・帯のホイール・ボタン列の整理（第2版 7-4）の仕様と記録

作成: 2026-11-12。作業ブランチ `claude/image-edit-menu`（7-3 と同じブランチ。版は 1.2.0 のまま）。
決定の元: `docs/07_開発計画の決定事項.md` 決定89。質問 RT2 の見本: `screenshots/rotate-question-rt2-icons.png`。
質問 RT1・ST1 の図は、会話の中に表示しただけで、ファイルには残していない。

## 目的

ユーザーの依頼（2026-11-12）による。

> 画像の回転機能を追加したいです。現在のツールバーのトリミングの右当たりに追加してほしいです。左右どちらも90°回転のボタンを追加してください。
> 画像だけではなく、PDFも回転できるようにしてください
> 左回転は文字ではなく円状に回転する矢印のアイコンのデザインにしてほしいです。モックイメージをいくつかください。
> ズームが400％マックスなんですけど、1000％マックスに変更してください。
> 編集モードの画面のツールバーに選択モードとハンドモードのボタンがありますが、各機能共有のページ上部メニューバーと被ってるので不要ですね。ツールバー側を削除してください。
> ツール画面の帯の下にスクロールバーがありますが、帯の上にカーソルがある時はクリックホイール操作で左右にスクロールするようにしてほしいです。
> ツール画面で「PDF か画像をここにドロップすると足します（画像は「変換する画像」の帯へ）」と記載されていますが、「PDF か画像をここにドロップすると帯を追加します」に文章を修正してください
> インストーラーさえ作ってくれればこちらでインストールします。今回は版上げしません。

ユーザーの言う「ツールバー（トリミングの右）」は、編集モードのときだけ出る、四角いボタンの下に名前を置いたボタン列（文書の中の呼び名は「道具の段」。`index.html` の `#edit-bar`）を指す。

| RT2 | アイコンは、紙の上に回る向きの半円の矢印を描いたもの（`assets/icons.js` の `pageRotateLeft`・`pageRotateRight`） | 質問 RT2 の答え「案D 半円矢印＋ページ」。ほかの案は、ページ編集モードと同じアイコン（推奨案だった）・円形矢印・円形矢印＋ページ |
| ST1 | ツールモードの帯で、ページが横に並ぶ段（PDF の帯と「変換する画像」の帯）にカーソルがあるとき、素のホイールで段を左右に送る。見出しの行（番号・ファイル名・ボタン）と帯の外では、今までどおり帯の並び全体が上下に動く | 質問 ST1 の答え「案A ページ段横移動（推奨）」。別案は、帯のどこでも左右に送る案 |

| C1 | 回転のボタンの名前は「左回転」「右回転」（ページ編集モードの同じ働きのボタンと同じ）。押したままにならないボタンで、`data-tool` ではなく `data-action` を持つ。窓が狭いときは「その他」の一覧にも入る | Claude の案 |
| C2 | 回す前に、入力中のテキストと描きかけを確定する（抽出と同じ。spec-4-2 確定事項8）。回転を覚える所と元に戻す仕組みは、ページ編集モードの回転（`page-actions.js` の `rotate`）をそのまま使うので、Ctrl+Z で戻せ、画像の保存（PNG・JPEG・PDF）も回った向きになる | Claude の案 |
| C3 | 編集モードのボタン列の［選択］［ハンド］を外す。上のツールバーの［選択］［ハンド］が、編集モードでは同じ `annotate.toggleTool` を呼ぶので、できることは減らない。spec-4b-3a 確定事項C1・spec-4b-3b 確定事項A1 を改める | ユーザーの指示 |
| C4 | 画像→PDF を選んでいるときの受け口の案内文を「PDF か画像をここにドロップすると帯を追加します」にする | ユーザーの指示（文のまま） |
| C5 | 帯のホイールは、段にページが全部収まっている（左右に動く余地が無い）ときは上下に動く。左右の端まで送ったあとは上下に移らない。Ctrl＋ホイール（紙の倍率）、Shift＋ホイールとタッチパッドの横の動きには触らない | Claude の案（質問 ST1 の図に書いた） |

倍率 1000% のときも、1 枚の canvas の画素の上限（`renderer/page-image.js` の `MAX_CANVAS_PIXELS`。約 1 億 3,400 万画素）は変えない。
超える分は倍率を下げて描いて広げるので、使うメモリの上限は 400% のときと変わらない。そのかわり、大きな紙（A3 以上）と高解像度の画面では、
高い倍率で少しにじむ。ツールモードの紙の倍率（50〜300%）は変えない。
