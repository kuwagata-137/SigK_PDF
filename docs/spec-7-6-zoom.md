# 倍率の基準・既定値・ズーム段階・数字入力（第2版 7-6）の仕様と記録

作成: 2026-11-13。作業ブランチ `claude/image-edit-menu`（7-3〜7-5 と同じブランチ。版は 1.2.0 のまま）。
決定の元: `docs/07_開発計画の決定事項.md` 決定93。質問 ZM1 の図: `screenshots/question-zm1-image-zoom.png`。質問 ZM2 の図: `screenshots/question-zm2-zoom-steps.png`。

## 目的

ユーザーの依頼（2026-11-13。1 通目）による。

> ツール画面の各帯の表示倍率100％は小さすぎるので、現在の200％を100％として設定してほしいです。
> 当然、デフォルトの表示倍率は100％とし、現在の2倍の大きさで表示されるようにします。
>
> 閲覧と編集画面のデフォルトの表示倍率も100％に変更してください。

同じ日の 2 通目による。

> 表示倍率は直接数字での入力もできるようにしてください。
> また、クリックホイールでのずーむの段階は33％→40％→50％から100％まで10％刻みにしてください。

「クリックホイールでのズーム」は、Ctrl キーを押しながらマウスのホイールを回したときの倍率の変化（ハンドのときは Ctrl なしのホイール）と読んだ。

## 今の作り（2026-11-12）

| 項目 | 今の作り |
|---|---|
| ツールモードの倍率 | 50〜300%（10 段: 50・67・75・100・125・150・175・200・250・300）。100% は帯のページの高さ 104px、分割画面のページの幅 104px、「変換する画像」の帯の画像の枠 104×72px（`docs/07` 決定83・spec-2-5 確定事項L）。アプリを閉じると 100% に戻る |
| 閲覧・ページ編集・編集の倍率 | 10〜1000%（20 段: 10・15・20・25・33・50・67・75・100・125・150・175・200・250・300・400・500・600・800・1000）。100% は実寸（1pt＝96/72 ピクセル）。文書を開くと［幅］（spec-1-1 確定事項8） |
| 画像のページ | 画像の 1 画素を 1pt として開く（spec-7-1）。4032×3024 画素の写真は、100% で幅 5,376 ピクセルになる |
| ズーム段階 | ホイール・ツールバーの［－］［＋］・Ctrl＋－／＋ キーのすべてが同じ段階で動く |
| 倍率の数字 | ツールバーの倍率の数字（`#zoom-value`）は表示だけで、入力できない |

## 実装記録（2026-11-13）

| ファイル | 変えた所 |
|---|---|
| `renderer/tools-zoom.js` | `PAPER_SCALE = 2` と `scale()`（表示する倍率×2）を追加し、段を ZS3 にした。CSS の `--paper-zoom` には scale を置く |
| `renderer/strip-layout.js`・`split-thumbs.js`・`image-strip-zoom.js`・`image-thumbs.js` | ツールモードの倍率を `get()` ではなく `scale()` で読む（紙の大きさと描く枚数の上限。ZT1・ZT3） |
| `image-thumbnail.js` | 画像のサムネイルの上限を 624px から 1248px にした（300%・画素比 2 で、にじまないため） |
| `renderer/viewer-layout.js` | ZOOM_STEPS を ZS1 にし、入力値を倍率に直す `parseZoomInput` を追加した |
| `renderer/viewer.js` | 開いた直後の倍率を `applyOpeningZoom`（100%。はみ出す画像だけ［全体］）にした（ZV1・ZV2） |
| `renderer/zoom-input.js`（新規） | 倍率の入力欄（ZI1〜ZI4） |
| `index.html`・`renderer/shell.css`・`viewer-controls.js`・`app.js` | `#zoom-value` を `<input>` にし、灰色のときは入力させない |

実装で決めたこと（Claude の案）:

1. 倍率の入力欄にはツールチップを付けない（文字を打つ欄にはツールチップを表示しない決まり。spec-2-5 確定事項J17。ページ番号の欄と同じ）。
2. 入力欄をクリックすると、数字を全部選択した状態にする（そのまま打ち直せるようにするため）。
3. 入力欄は、ふだんは今までの数字と同じ見た目にし、カーソルを合わせると枠を表示し、フォーカスがあるときは白い欄にする。

## テストの範囲

- ツールモード: 100% で帯のページの高さ 208px・分割画面のページの幅 208px・画像の枠 208×144px（ZT1）。段階と範囲（ZS3・ZT2）。描く枚数の上限（ZT3）。
- 閲覧: PDF を開くと 100%（ZV1）。大きな画像は［全体］、収まる画像は 100%（ZV2）。段階（ZS1）とホイール・ボタン・キー（ZS2）。
- 入力欄: Enter・ほかの所のクリック・Esc、%・全角・小数・範囲外・数字でない入力、ツールモードと閲覧の両方、灰色（ZI1〜ZI4）。
- 起動確認（ウインドウを表示しない）: ツールモードの 100%、PDF と写真を開いたときの倍率、倍率の入力。
