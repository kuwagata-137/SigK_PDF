# 印刷画面を Acrobat Reader の［印刷］ダイアログと同じにする（第2版 7-7）の仕様と記録

作成: 2026-11-13。作業ブランチ `claude/print-dialog`（`claude/image-edit-menu` の 4442eaa から作った。版は 1.2.0 のまま）。
決定の元: `docs/07_開発計画の決定事項.md` 決定94。質問の図: `screenshots/question-pr1-properties.png`・`question-pr2-annotation-terms.png`・
`question-pr3-substitutes.png`・`question-pr4-screenshots.png`。

## 目的

ユーザーの依頼（2026-11-13）による。

> 印刷のダイアログをアクロバットリーダーと全く同じにしてください。

依頼には、Acrobat Reader の［印刷］ダイアログの画面写真が 2 枚付いていた（ページサイズ処理で［サイズ］を選んだ状態と、［複数］を選んだ状態）。
画面写真には社内のプリンター名と文書が写っているので、リポジトリには入れない（このリポジトリは公開）。

「ダイアログ」は、SigK PDF の印刷画面（Ctrl+P とツールバーの印刷ボタンで開く `#print-dialog`）と読んだ。
構成・文言・配置・見た目・動きを Acrobat と同じにする。Electron で同じ動きにできない所は、質問 PR1〜PR3 で決めた。

## 用語

| 用語 | 指すもの |
|---|---|
| 印刷画面 | SigK PDF の印刷の画面（`#print-dialog`。ツールチップ「印刷画面を開きます。」と同じ） |
| Windows の印刷画面 | `webContents.print({ silent: false })` が表示する Windows 標準の画面。この改修の後は使わない |
| Acrobat の［印刷］ダイアログ | Acrobat Reader の画面。この文書の「Acrobat」は Acrobat Reader（日本語版・Windows）を指す |
| 印刷設定 | Windows のプリンターの「印刷設定」画面（プリンターの会社が作った画面） |
| シート | プリンターへ送る 1 ページ分の面（両面印刷では紙の片面）。Acrobat の「各シート内でページを自動回転」と同じ言葉 |
| 書き込み | SigK PDF の用語（ユーザーが決めた）。Acrobat の「注釈」と同じもの。印刷画面の文言は「注釈」を使う（質問 PR2） |

## 事前調査（2026-11-13）

| 調べたこと | 分かったこと |
|---|---|
| Electron 44 の印刷 | `webContents.print` は silent・deviceName・copies・collate・color・duplexMode・landscape・pageSize・margins・pageRanges・pagesPerSheet・usePrinterDefaultPageSize を受け付ける（`node_modules/electron/electron.d.ts`）。`getPrintersAsync()` は name・displayName・description・options を返し、既定のプリンター・用紙サイズ・両面の可否は返さない |
| Electron でできないこと | プリンタードライバーの設定画面を「この印刷だけ」に使う形で開く API、Windows の「ページ設定」画面を開く API、給紙トレイを指定するオプションはない |
| プリンターの既定の設定 | Windows の PowerShell の `Get-PrintConfiguration` で、プリンターごとに PaperSize・DuplexingMode・Color・Collate と、PrintTicketXML（用紙の寸法 µm）・PrintCapabilitiesXML（印刷可能領域・用紙サイズ一覧・両面の可否）を取得できる。実測で 1 台 61〜1031 ms。取得できないプリンターもある（アクセス拒否 1 台） |
| 既定のプリンター | レジストリ `HKCU\Software\Microsoft\Windows NT\CurrentVersion\Windows` の Device に「プリンター名,winspool,ポート」の形で入っている |
| 社内のプリンター | このパソコンには 30 台が登録されている。既定の用紙が A5・B5・A3 のもの、既定が両面のもの、手差し用のものがある。用紙を A4 に固定すると、これらの既定を壊す |
| Acrobat の文言の出所 | ①ユーザーの画面写真 2 枚 ②Adobe 日本語ヘルプ（「印刷設定」「1 枚に複数のページを印刷」「小冊子の印刷」「大判文書の印刷」「Acrobat Reader での PDF の印刷」「用紙の両面に印刷」） ③ASCII.jp の Acrobat DC 連載の画面写真（2017〜2018 年）。版によって文言が違う所がある |
| 注釈の一覧 | ASCII.jp の画面写真（2017 年）: ［注釈の一覧(T)］を押すと「印刷する文書に注釈の一覧テキストを含めますか？」［はい(Y)］［いいえ(N)］を表示し、はいなら、書き込みのあるページの後ろに一覧ページ（番号・作成者・タイトル・日付・本文）を印刷する |
| インク / トナーを節約 | Adobe の資料（Customization Wizard の説明）: コンテンツを最適化して印刷し、最大で 15% 節約する。通常、印刷品質に影響しない。Adobe のコミュニティの回答: インクを減らす専用の ICC プロファイルで色を変換する |
| pdf.js の印刷 | pdf.js 6.3.289 の `render` は `printAnnotationStorage` を受け付ける。SigK は `annotationStorage` の noView で、pdf.js に描かせない書き込みを決めている（`renderer/annotation-import.js`）。ページの内容と書き込みの差分を取る方法は `renderer/mosaic-paint.js` にある |

## 配置の計算（Claude の案）

- 印刷可能領域: プリンターの PrintCapabilitiesXML の PageImageableSize。取得できない時は用紙の四辺から 4.23 mm 内側。
- サイズ: 合わせる＝印刷可能領域に収まる最大の倍率（拡大もする）。実際のサイズ＝100%（用紙の中央。はみ出た所はプリンターが切る）。特大ページを縮小＝印刷可能領域より大きいページだけ縮小。カスタム倍率＝1〜1000%。
  プレビューの「倍率」は、表示しているページの倍率。
- 向き: 自動＝ページの縦横に合わせて用紙の向きを決める（印刷する画像は、用紙の向きに合わせて回して作る）。縦・横＝用紙の向きを固定する。
- 複数: 1 枚あたりのページ数 2・4・6・9・16 は、用紙の向きに合わせて列と行を決める（例 縦の用紙の 2 ページは 1 列 2 行）。カスタムは列と行を 1〜99 で指定する。
  ページの順序は、横＝左から右・上から下、横 (右から左)、縦＝上から下・左から右、縦 (右から左)。ページ境界線を印刷は、各ページの範囲に細い線を描く。各シート内でページを自動回転は、枠に合う向きにページを回す。
- 小冊子: ページ数を 4 の倍数にして（足りない分は白紙）、中綴じの順番に並べる（左綴じの 1 枚目の表＝最後のページと 1 ページ、裏＝2 ページと最後から 2 番目）。
  両面で印刷は短辺を綴じる両面印刷で送る。片面で印刷 (表側)・(裏側) は、表だけ・裏だけを送る。開始ページ・終了ページは、印刷する紙の範囲（1〜紙の枚数）。縦長左・縦長右は、用紙を回さずに上下に 2 ページを並べる。
- ポスター: 倍率をかけたページを、印刷可能領域の大きさのタイルに分ける。隣のタイルと「重なり」の幅だけ重ねる。タイルマークは、重なりの端を示す線。ラベルは「ファイル名 日時 ページ 番号 (列,行)」。大きいページのみを分割は、倍率をかけても印刷可能領域に収まるページを分割しない。
- 偶数または奇数ページと逆順に印刷は、印刷するページの一覧に当ててから配置する。小冊子では使えない（灰色）。
- 注釈とフォーム: 文書と注釈＝今と同じ（未保存の書き込みも印刷）。文書＝書き込みを印刷しない（フォームフィールドは印刷する）。文書とスタンプ＝スタンプだけ印刷する。フォームフィールドのみ＝ページの内容を印刷せず、フォームフィールドだけを印刷する。
- 注釈の一覧(T): 確認画面で［はい(Y)］を選ぶと、この印刷では、書き込みのあるページの後ろに一覧ページを入れる。一覧ページの形は「注釈の一覧 :ファイル名」「ページ :番号」と、書き込みごとの「番号 : n 作成者 : 名前 タイトル : 種類 日付 : 年/月/日 時:分:秒」と本文。
- PDF のページサイズに合わせて用紙を選択: ページごとに、プリンターの用紙サイズ一覧から、ページが倍率 100% で収まる最小の用紙を選ぶ。用紙サイズが変わる所で印刷を分ける。

## 実装で決めたこと（Claude の案。2026-11-13）

| 番号 | 決めたこと | 理由 |

## 手で確かめる筋書き（ユーザーの実機。用紙に印刷するので自動化しない）

1. 1 ページ: 文書を開き、ツールバーの［印刷］で印刷画面を開く。現在のページ(U) を選んで［印刷］を押す。進行状況画面が表示され、プレビューと同じ向き・倍率で 1 枚印刷される。
2. 複数: ［複数］で 1 枚あたりのページ数を 4 にして［印刷］を押す。1 枚に 4 ページが、ページの順序（横）のとおりに並ぶ。
3. 小冊子: 8 ページ以上の文書で［小冊子］（両面で印刷）を選んで［印刷］を押す。両面に印刷され、二つ折りにすると 1 ページから順に読める。
4. ポスター: ［ポスター］で倍率を 200% にし、タイルマーク(K) とラベルをオンにして［印刷］を押す。タイルを貼り合わせると、元のページになる。
5. 両面: ［サイズ(I)］で 用紙の両面に印刷(B) をオンにし、長辺を綴じる(L) で 4 ページを印刷する。裏表の向きが、長辺で綴じた向きになる。
6. ［プロパティ(P)］: プリンターの印刷設定が開く。用紙サイズか両面を変えて閉じると、印刷画面の用紙サイズ・用紙の両面に印刷(B)・グレースケール (白黒) で印刷(Y) の表示が変わる。
7. 用紙選択: A4 と A3 のページが混ざった文書で、PDF のページサイズに合わせて用紙を選択(Z) をオンにして印刷する（A3 の用紙があるプリンター）。ページごとに用紙が切り替わる。
8. インク / トナーを節約: オンにして印刷すると、オフの時より少し薄く（15%）印刷される。
