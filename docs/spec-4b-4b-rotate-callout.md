## 目的

編集モードのテキストの書き込みを、**四角・丸と同じく自由な角度で回せる**ようにし（回転のつまみ・右パネルの回転の行・Shift で 15°。
F-05-14 の回転）、**吹き出し（角の丸い箱と三角のしっぽ）**を置けるようにする（しっぽの先の白いつまみで向きを変える。F-05-15）。
保存は PDF の決まりの欄（外観の `/Matrix`・`/IT`・`/CL`・`/RD`・`/LE`）だけで行い、開き直しても同じ見た目のまま直せる。

塊④は 2 本に割った（決定56）。前半の ④-a（テキストの書式）は PR #33 でマージ済み。前のセッションの引き継ぎ文書はこのセッションの実行環境に
無かったので、`docs/spec-4b-4a-text-format.md` の事前調査 F・G の要約と決定57 を土台に、事前調査をやり直した（決定58 ①）。

## 含めるもの / 含めないもの

| 含めるもの | 含めないもの |
|---|---|
| テキストの回転（回転のつまみ・回転の行・Shift で 15°。四角・丸と同じ） | 他のアプリの FreeText（吹き出し・回したものを含む）を直せるようにすること（決定57 ②。表示のみのまま） |
| 今までの形のテキストを回すと新しい形へ移す（④-a の書式と同じ規則） | 線と矢印のしっぽ（Acrobat の吹き出しの形。決定57 ⑩で採らない） |
| 吹き出しの道具（道具の段のテキストの隣）・置く・打つ・直す | テキストと吹き出しを互いに変えること（道具で決まる） |
| しっぽの先のつまみ（Shift で横か縦）、幅のつまみ、回転 | 吹き出しの枠線の線種（破線・雲形）。テキストと同じく実線だけ |
| 吹き出しの書式はテキストと同じ行（文字の色・大きさ・太字・斜体・塗り・枠線・太さ・不透明度） | しっぽの根元の位置を手で決めること（先に合わせて自動） |
| 吹き出しの「次に付ける値」をテキストと別に覚える（決定59 ④） | 複数選択での回転の行（1 つを選んだときだけ。四角・丸と同じ） |
| 保存・読み戻し・印刷・フラット化 | 回したテキストでの日本語入力（IME）の確かめ。この環境では試せない（Phase 5 塊③） |

## 事前調査（2026-10-04・Linux のクラウドのコンテナ・Electron 44.5.1・pdf.js 6.4.299（Node と `@napi-rs/canvas`）・pdf-lib 1.17.1・scratchpad の検体のみ）

試作は scratchpad の使い捨て（リポジトリの部品で保存した検体を、Node の pdf.js で倍率 2 で描いて画素を比べるもの、見本の HTML を Electron の
隠した窓で撮るもの）。

### A. 環境

- 文書の前提（Windows 11 実機）と違い、このセッションは Linux のクラウドのコンテナで動いた。pdfjs-dist は 6.3.289 から 6.4.299 に上がっていた
  （lockfile を持たないため）。Electron 本体は `npm install` では入らず、`node node_modules/electron/install.js` で入れ直した。
- `npm test` は 2,150 件中 2,149 件が緑。残る 1 件（`test/pdf-write.test.js` の「読み取り専用のファイルには…断る」）は root で動かしているため
  0o444 のファイルにも書けてしまう、この環境だけの失敗（CI は緑）。
- 起動確認は `xvfb-run -a` と `--no-sandbox` で隠した窓が描けた。配布物の代わりに `electron-builder --linux dir` の展開版でも通った（決定58 ②）。
- 画面の日本語は IPAGothic になる（Yu Gothic UI が無い）。書き込みと PDF の文字は同梱の Noto Sans JP なので変わらない。

### B. 回したテキスト — 外観の `/Matrix` で回せば pdf.js は形も大きさも色も正しく読む

- 本物の `wrappedAppearanceOf` の外観に、`worker/shape-rotation.js` の `matrixOf` で `/Matrix`、`rectOf` で `/Rect` を書いた検体 60 通り
  （ページの `/Rotate` 0・90 × 文字の向き 0・90・270 × 角度 0・15・90・137・300 × 不透明度 1・0.5、塗りと枠線を含む）。
- 回していない同じテキストの絵を箱の中心まわりに回したものと、回した検体の絵を比べると、1 画素の幅で形が外れた画素は 60 通りとも 0。
- pdf.js は `/Matrix` があっても外観から大きさ・色・行を読む（`defaultAppearanceData`・`textContent`）。半透明の透明グループの外の文字の命令も効く。
- `rotationOf` は 60 通りとも角度と回す前の箱をそのまま返す（0° は null）。

### C. ゆがみの判定 — SigK の 90°・270° の向きのテキストに当たる

- `appearance-reader.js` の `skewedContent` は、`cm` の b・c が 0 でないものを「ゆがみ」とみなす。SigK のテキストは向き 90・270 で
  `0 1 -1 0 cm` などを書くので、回していなくても 40 通りすべてで true になった（向き 0 は false）。
- → FreeText の回転の読みでは `skewedContent` を見ない。直せるのは SigK のテキストだけで（`/DA` の書体名で見分ける）、他のアプリの
  FreeText は表示のみなので、中身のゆがみを見る必要が無い。

### D. 吹き出しの外観 — 1 本の輪郭を丸く結べば pdf.js と canvas が一致する

- 角の丸い箱としっぽの三角を 1 本の閉じた輪郭で描き、`/IT /FreeTextCallout`・`/CL`・`/RD`・`/LE /None` を付けた検体を、先の位置 8 方向と
  太い線（6pt）で描いた。pdf.js は `it: 'FreeTextCallout'` を返し（`pdf.worker.mjs` 59149 行。注釈の基の部分が読む）、絵は外観どおり。
- 同じ輪郭を canvas で描いた絵と比べると、**角を丸く結ぶ（`1 j`・`lineJoin = 'round'`）なら 8 方向とも形の外れは 0**。尖らせる（`0 j`）と
  6pt の線で先の形が外れる（37 画素）。丸く結べば `/BBox` の余白は線の太さの半分で足りる。
- pdf.js は `/CL`・`/RD` を読まない。FreeText の大きさと色は外観の最初の文字の命令から読む（④-a と同じ）。

### E. `/RD` の並び — 規格の文と主な実装が食い違う

- 規格（1.7 表174・2.0 表180）の文は「左・上・右・下」。PDFBox の `applyRectDifferences` と MuPDF の `pdf_annot_rect` は、どちらも
  ［左 下 右 上］として足し引きする（`/Rect` の左下の x・y に 0 番目・1 番目を足す）。pdf.js は読まない。
- 既存の読み手 `renderer/annotation-box-details.js` は規格の文の並びで読むが、雲形は 4 つが同じ値なので食い違いが表に出ない。
- → 吹き出しは［左 下 右 上］で書いて読む（決定59 ③）。他のアプリが外観を作り直すときに文字の箱がずれにくい。

### F. CheckListMaker の吹き出しと回転（`kuwagata-137/CheckListMaker` `574cc68` の `index.html` を読んだ）

- 箱: 余白は大きさ×0.55、行の高さは大きさ×1.3、12 字で折り返す（テキストと同じ）。
- しっぽ（`calloutPath`）: 出る辺は、箱の中心から先への差 (dx, dy) で `|dy|/高さ ≥ |dx|/幅` なら上か下、そうでなければ左か右。根元の半幅は
  max(10, 大きさ×0.6) を「辺の長さ − 角の丸み×2」の半分 − 1 で抑え（4 を下回らない）、根元の中心は先に合わせて辺の上を「角の丸み＋半幅」から
  「辺の長さ − 角の丸み − 半幅」の間で滑る。角の丸みは min(10, 幅/2, 高さ/2)。角は丸く結ぶ。塗りは白、線の太さの既定は 2。
- 置いた直後の先は、箱の左上から右へ min(幅×0.25, 40)、下へ 高さ＋大きさ×1.6。打っている間は先を引くまで本体の下に付いてくる（`tipAuto`）。
  確定したら先は固定。
- 先は回す前の座標で持つ。箱を動かすと先も同じだけ動く。先を引く差は回す前の軸へ直して足す（`localDelta`）。Shift は画面での差の大きい方だけを
  残す（画面の横か縦）。
- 当たりは箱と、先の周り 14 画面 px。回転の中心は箱（しっぽを含まない）の中心で、Shift で 15° 刻み。
- 回したテキストの幅を変えるとき、CheckListMaker は回す前の左上を動かさないので、回した絵が横へずれる（見本 `screenshots/phase4b-4b-tail.png` 下段 B）。

## 確定事項

### A. 書き込みの持ち方（`renderer/free-text-entry.js`・`annotation-entry.js`・`annotation-entry-rules.js`）

1. テキストの entry に **`angle`**（画面で時計回りの度。0 より大きく 360 未満。0 は持たない）を足す。`rect` は回す前の箱、`quads` は回した
   4 隅（四角・丸と同じ。spec-4b-2 確定事項1〜4）。回転の中心は `rect` の中心。今の `rotation`（置いたときの表示の向き 0・90・180・270。
   `/Rotate`）とは別の欄で、画面に描く角度は両方を足したもの。
2. 回せるのは新しい形（`width` を持つ）だけ。**今までの形を回すと、書式を付けたときと同じく固定の幅の新しい形へ移す**
   （spec-4b-4a 確定事項A2。`free-text-style.js` の `fixedWidthOf`。行の並びは変わらない）。
3. 吹き出しは、テキストの entry に **`tip: [x, y]`**（しっぽの先。回す前の紙の座標で、`rect` と同じ座標）を足したもの。種類（`kind`）は
   `'text'` のまま（書式の行・複数選択・入力欄・折り返し・保存の多くをテキストと共有する）。`tip` を持つのは新しい形だけ。
4. 書き換えられる欄（`PATCH_FIELDS`）に `tip` を足し、`angle` をテキストにも許す。写し・比較・ワーカーへ渡す形にも `angle`・`tip` を足す。
5. 吹き出しは**塗りと枠線を両方なしにはできない**（しっぽが見えなくなる。四角・丸と同じ規則。起草者の判断）。

### B. 回したテキストの箱の変化（新 `renderer/free-text-turn.js`。純関数）

1. 箱が変わる操作（打つ・幅のつまみ・文字の大きさ・書式・動かす）は、今までどおり回す前の座標で新しい箱を組み、**回していれば、新しい箱の
   中心を元の中心まわりに回した位置へずらす**（`renderer/shape-resize.js` の大きさ変えと同じ式）。回す前の座標で動かさなかった点
   （打つ・大きさ・書式では表示の左上、左の幅のつまみでは中身の右）は、この式で紙の上でも動かない。**打って伸びるときは回した左上が
   動かない**（決定59 ①。CheckListMaker の「回す前の左上」とは違う）。
2. `quads` は回した 4 隅にする（吹き出しもしっぽを含まない箱の 4 隅）。
3. **吹き出しのしっぽの先は、箱が変わっても紙の上で動かさない**（決定59 ②）。箱を置き直したあと、元の先の紙の上の位置を新しい箱の
   中心まわりに戻して `tip` にする（回していなければ `tip` はそのまま）。
4. **箱を動かすと `tip` も同じだけ動く**（決定59 ②。まとめて動かす・Ctrl＋ドラッグの写しも同じ）。
5. **回すと `tip` も箱の中心まわりに一緒に回る**（`tip` は回す前の座標のまま、`angle` だけが変わる。決定59 ②）。

### C. 画面・つまみ・回転の行・印刷

1. 描く位置: `free-text-shape.js` の `layoutOf` は、回していれば表示の左上を箱の中心まわりに回した点に置き、角度に `angle` を足す
   （SVG・印刷の canvas・半透明の別の層が同じ位置になる）。
2. 選んだテキスト・吹き出しの枠は回した箱。左右の幅のつまみは回した左右の辺の中点の外。**回転のつまみ**は文字の向きでの上の辺の外
   （26px）、見える範囲から出るときだけ下の辺の外（四角・丸と同じ規則。spec-4b-2 確定事項10）。
3. 吹き出しは**しっぽの先に白いつまみ**（id `tip`、種類 `tip`）。重なるときに先に当てる順は 回転 → しっぽ → 角 → 辺・幅 → 端。
4. 当たり: 回したテキストは回した箱（回す前の座標へ戻して箱で見る）。吹き出しは箱に加えて、しっぽの三角（回す前の座標で三角の中か、
   辺から当たりの余裕の内）。
5. **回転の行**は、自前のテキスト・吹き出しを 1 つ選んだときにも出す（今までは四角・丸だけ）。次に置くテキスト・吹き出しは 0°。
6. 回転のつまみ・回転の行・Shift で 15°・0°/90°/180°/270° のボタン・続けた変更の 1 世代は四角・丸と同じ（`shape-resize.rotatedBy`・
   `annotation-angle-row.js`）。
7. 吹き出しの輪郭は SVG の `<path>`（塗りと線を 1 本で。`stroke-linejoin: round`）、印刷は canvas の同じ輪郭（`lineJoin = 'round'`）。
   文字は今までどおり箱の中。テキストの四角の塗りと枠線は描かない。

### D. 入力欄（`renderer/free-text-editor-node.js`・`annotate-text.js`）

1. 回したテキスト・吹き出しを直すときは、**入力欄を同じ角度に回して**回した左上に出す（画面の角度＝表示の向きの角度＋`angle`。回転の基点は
   今までどおり入力欄の左上）。入力中に伸びても左上は動かず、確定したときに B1 の式で箱を置き直すので、確定の前後で位置がそろう。
2. 吹き出しを打っている間は、入力欄の下に吹き出しの輪郭（塗り・枠線・しっぽ）を描き、入力欄の地は透明にする（テキストの塗りを入力欄の地に
   出す ④-a の確定事項E2 は、吹き出しには当てない）。
3. **新しい吹き出しを打っている間は、しっぽの先が本体の下に付いてくる**（CheckListMaker の `tipAuto`）。先は、表示の左上から右へ
   min(幅×0.25, 30pt)、下へ 高さ＋大きさ×1.6。確定した時点の位置に固定し、以後は打っても動かない（B3）。

### E. 吹き出しの形（新 `renderer/callout-geometry.js` と、同じ式の新 `worker/callout-outline.js`。一致はテストで見張る）

1. 座標は**箱の表示の左上を原点にし、表示の右と下を正にした向き**（文字の向き）。箱は [0, 0, 幅, 高さ]、先も同じ向きで表した点。紙の座標との
   行き来は `free-text-layout.js` の `shiftOrigin` とその逆。
2. 出る辺は CheckListMaker と同じ（事前調査 F）。根元の半幅は 大きさ×0.6 を「辺の長さ − 角の丸み×2」の半分 − 0.5 で抑え、2pt を下回らない。
   根元の中心は先に合わせて辺の上を滑る。
3. 角の丸み ＝ min(大きさ×0.6, 幅/2, 高さ/2)。輪郭は箱の外周から枠線の太さの半分だけ内側（テキストの枠線と同じく箱の内側に描く。枠線が無ければ
   外周そのもの）。先の点は動かさない。
4. 角と先は丸く結ぶ（事前調査 D）。塗りは同じ輪郭の中。
5. 余白は今のテキストと同じ式（飾りがあれば max(2, 大きさ×0.3)＋枠線の太さ。spec-4b-4a 確定事項B2）。

### F. しっぽのつまみ（新 `renderer/callout-tail.js`。`annotate-transform.js` が呼ぶ）

1. 引いた差を回す前の座標へ直して `tip` に足す。**Shift を押すと、画面での差の大きい方の向きだけを残す**（画面の横か縦。CheckListMaker と
   同じ。起草者の判断）。
2. 引いている間は下見、離したときに 1 世代（四角・丸のつまみと同じ）。Esc・左＋右・選択の変更で取りやめる。
3. 先が箱の中にあっても特別な扱いはしない（CheckListMaker と同じ）。

### G. 道具・右パネル・次に付ける値

1. 道具の段のテキストの隣（区切りなし）に**「吹き出し」**のボタン（決定57 ⑦）。アイコンは自作のインライン SVG（角の丸い四角に三角のしっぽ）。
   道具の名前は `callout`。カーソルはテキストと同じ。
2. 紙を押して離すと、その点を表示の左上にして入力欄を開く（テキストと同じ。入力欄は空から始め、空のまま確定すると置かない。起草者の判断。
   CheckListMaker の「ここをクリック」の見本の文字は入れない）。
3. 右パネルの行はテキストと同じ並び（文字の色・文字の大きさ・書式・塗り・枠線・枠線の太さ・不透明度）に回転の行。種類の名前・注釈一覧の
   名前は**「吹き出し」**。
4. **次に付ける値はテキストと別に覚える**（決定59 ④）: 文字の色・文字の大きさ・太字・斜体・塗り・枠線・枠線の太さ・不透明度。既定は
   文字の色 #222A35・塗り #FFFFFF・枠線 #C00000（決定57 ⑪）・枠線の太さ 2pt（決定59 ④）・大きさ 12・不透明度 100%。`settings.json` には
   `annotColors.callout`・`annotOpacity.callout`・`annotCalloutStyle`（大きさを含む）として書く。
5. 吹き出しを直したときの値は、吹き出しの次に付ける値にする（テキストの値は変えない）。
6. ヒント: 「紙の上を押すと吹き出しを置きます。しっぽの先の白いつまみを引くと向きが変わります（Shift で横か縦）。」（見本 `phase4b-4-callout.png`）。

### H. 保存（ワーカー。`worker/free-text-wrapped.js`・`free-text-fields.js`・新 `worker/free-text-callout.js`）

1. 回したテキスト: 外観の外側の Form に `/Matrix`（`worker/shape-rotation.js` の `matrixOf`。箱の中心まわり）、`/BBox` は回す前の箱、注釈の
   `/Rect` は `/BBox` を `/Matrix` で写した外接（小数 2 桁。四角・丸と同じ。事前調査 B）。半透明の G0 は回さない（外側だけ）。
2. 吹き出し: **`/IT /FreeTextCallout`・`/CL [先の x y 根元の中心の x y]`**（紙の座標。回していれば回した位置）**・`/LE /None`・
   `/RD [左 下 右 上]`**（決定59 ③）。`/BBox` は回す前の箱と先を含む外接に枠線の太さの半分（無ければ 0.5）を足したもの。`/RD` は `/BBox` と

## 起草者の判断で決めたもの
