## 目的

編集モードで、**書き込みの色をパレット（テーマの色 10・濃淡 5 段・標準の色 10）から選べ、四角・丸は塗りと線なしを選べる。線種は
実線・破線・雲形（雲形は四角・丸だけ）から選び、線の太さは 1〜40pt、不透明度は 10〜100% を、スライダーと数値欄で選べる。スライダーを
動かしている間は下見が出て、離すと 1 世代だけ積まれる。保存すると PDF 標準の注釈（外観付き）の `/C`・`/IC`・`/BS`・`/BE`・`/RD`・`/CA` に
書かれ、開き直しても同じ見た目のまま直せる**（F-05-11）。

右パネルは CheckListMaker の画像エディタに寄せ、色の行には今の色を示すチップを 1 つ置き、押すとパレットが開く（決定47）。①-a の
読み戻しの口の答えを使い、①-a が表示のみにした他のアプリの書き込み（塗り・線なし・破線・雲形・`/RD`）も直せるようにする。

## 事前調査（2026-09-28・Windows 11 実機・Node 24・Electron 44・pdf.js 6.3.289・pdf-lib 1.17.1・fixtures と scratchpad の検体のみ）

塊①をまとめて起草していたときに行った事前調査 A〜F のうち、①-b にかかわる C・D・F をここに置く。A（pdf.js が返すもの）・B（読み戻しの口）・

### C. 画面 — 図形 100 個の層の描き直しは 0.8ms

- `annotation-layer.draw` で図形 100 個の層を描き直す時間（DOM を組んでスタイルを当てるまで）: 中央値 0.8ms・95% 1.3ms。
  倍率 100% と 400% で同じ。図形を描いている間は今も mousemove のたびに表示中の全ページの層を描き直しており、スライダーの
  input ごとの下見も同じ重さで済む。
- range の input は動かしている間に何度も、change は離したときに 1 回出る。キーボードの矢印では 1 押しごとに両方出る（HTML の
  決まり。人の操作でしか確かめられないので、実装後の目視で見る）。
- `<input type="color">` は、Windows では OS の色の選択が開く見込み（推測）。窓を出さない起動確認では開けないので、値を入れて
  change を流して確かめ、開き方はユーザーの目視で見る。
- 幅 260px の右パネルに、色のチップと値・線種のボタン 3 つ・スライダー＋数値欄＋単位が収まる（モック）。

### D. 塗りと不透明度の見え方 — 塗りと線を別々に薄めると、重なる帯が濃く出る

白紙に 7 通り（塗り付き矩形 50%・塗り付き楕円 50%・線なしの塗り 50%・塗りなしの線 50%・30pt 角に 40pt・塗り付き楕円 100%・
白い塗りに細い線 35%）を置き、外観の組み方を 3 通りにして、pdf.js で描いた画素（倍率 2）と、画面の描き方（SVG の
`<g opacity>` に塗りと線を 1 要素で描く）の画素を比べた。

| 組み方 | 塗り付き矩形 50% | 塗り付き楕円 50% | ほかの 5 通り |
|---|---|---|---|
| v1: `/GS gs` のあと、塗りと線を 1 本の path で `B` | 差 41・15,552 画素 | 差 42・13,526 画素 | 楕円 100% を除き差 0 |
| v2: 透明グループ（`/GS gs /G0 Do`。`G0` は `/Group << /S /Transparency >>` の Form で、中は不透明で描く） | 差 0 | 差 28・906 画素（縁） | 同上 |
| v3: 塗りを線の内側の縁までに限る | 差 0 | 差 27・1,154 画素（縁） | 同上 |

- v1 は、線の内側半分（塗りと重なる帯）が濃く出る（画面の [236,149,149] に対し [236,142,108]）。今の印刷の描き方（要素ごとに
  `globalAlpha`）も同じ帯が出る。別の canvas に不透明で描いてから alpha で重ねると、画面と一致する。
- v2 をフラット化のワーカー関数で焼いた結果は、焼く前と全画素一致（200 万画素中の差 0）。
- 楕円の縁の差は、塗りの有無によらず出る。ベジェ 4 本（κ = 0.5523）と SVG の楕円の違いで、`spec-4-3` 事前調査 E で見た性質と
  同じ。塗り付き楕円 100% でも、差が 32 を超える画素は箱の 1.6%。
- **線が箱より太いと、何も描かれない**（30pt 角に 40pt。画面も pdf.js も白のまま）。線の中心を線幅の半分だけ内へ寄せる今の規則で
  箱がつぶれるためで、今も 8pt の線で 8pt より小さな箱を描けば同じことが起きる。

### F. 設定の移し替え

今の `settings.json` の値（候補の色、太さ 1・2・3・5・8、不透明度 1・0.75・0.5・0.25）は、新しい検証（色は `#rrggbb`、太さは
1〜40 の整数、不透明度は 0.1〜1）をすべて通る。古い版（今の `settings.js`）に新しい値を読ませると、候補に無い色は種類の既定の色へ、
17pt は 2pt へ、35% は 100% へ落ち、新しいキー（`annotFills` など）は捨てられる。壊れはしない。

2026-09-29 追記: 既定の色をパレットの色へ寄せると決まった（決定47 論点12）。検証は通るものの、残っている「最後に使った色」が今の候補の
色のままでは、パレットに印が付かず、既定の色を替えた効き目も常用の設定には出ない。候補の色とちょうど同じ値だけを移し替える（確定事項15）。

## 確定事項（〔H〕の印は事前調査 H の後で書き足す）

### A. 右パネル（モック `screenshots/phase4b-style.png`・`-selected.png`・`-palette.png`・`-text.png`）

1. 行の並び: 種類 → 色 → 塗り → 線種 → 線の太さ・文字の大きさ → 不透明度 → 本文 → 作成者 → ページ → 対象の文字 → ヒント。色の行の
   見出しは、図形・ペンが「線の色」、テキストが「文字の色」、それ以外が「色」。
2. 色の行: 今の色を示すチップ（幅 44px の色見本と ▼）を 1 つ置き、右に値（`#RRGGBB`）か「なし」を添える。押すとパレットが開く
   （決定47 モック。CheckListMaker と同じ）。今の候補の丸は外す。
3. 「塗り」の行は四角・丸だけに出す（選んでいる書き込みか、四角・丸の道具を持っているとき）。チップの形は色の行と同じで、「なし」は
   白地に赤の斜線で示す。既定は「なし」。
4. 線なし: 四角・丸の「線の色」のパレットの下の段に「線なし」を置く。線と塗りは両方「なし」にできない（片方が「なし」のとき、もう片方の
   「なし」は押せない）。四角・丸のヒントに「線と塗りを両方「なし」にはできません。」を足し、塗りがあるときは「塗りは下の文字を隠すだけで、
   文字は検索やコピーで取り出せます。」を添える（論点5）。
5. 「線種」の行: 四角・丸は 実線・破線・雲形、直線・矢印は 実線・破線 のボタン（40×30。絵はインライン SVG）。ペン・テキスト・ノート・
   ハイライト・下線・取り消し線には出さない。既定は実線。
6. パレット（モック `-palette.png`）: チップを押すと、右パネルの左、紙の上に重ねて開く。幅 268px、左端は右パネルの左端から 276px 左、
   上端は行の上端の 40px 上（90px より上には出さず、窓の下にはみ出すなら上へずらす）。中身は 見出し（行の名前）→「テーマの色」→
   テーマの色 10 → 濃淡 5 段（10 列）→「標準の色」→ 標準の色 10 → 下の段［なし］［その他の色…］。［なし］は塗りと、四角・丸の線の色
   だけに出す（押せないときは薄く）。今の色に印を付ける。外を押す・Esc・色を選ぶ、のどれでも閉じる。［その他の色…］は OS の色の選択
   （隠した `<input type="color">`）を開き、選んだ色を当てて閉じる。
7. 線の太さと不透明度（モック）: スライダー＋数値欄＋単位（pt・%）。太さは 1〜40、不透明度は 10〜100 の整数で、スライダーも 1 刻み。
   数値欄は Enter か欄の外で確定し、範囲の外は端へ、小数は四捨五入する（0 → 1、41 → 40、35.4 → 35）。読み込んだ小数の太さ（1.5pt
   など）はそのまま見せ、動かすと整数になる。
8. 下見と確定: 書き込みを選んでいてスライダーを動かしている間（input）は、その書き込みを下見の値で描き直す（履歴に積まない）。離したとき
   （change）と数値欄の確定で 1 世代積む。何も選んでいなければ下見は無く、「次に付ける値」として覚えるだけ。下見の途中で Esc・選択の
   変更・別の欄の操作があれば下見を捨てる。
9. 表示のみの書き込みには、色・塗り・線種・太さ・不透明度の行を出さない（今のまま）。

### D. 書き込みの持ち方（`renderer/annotation-entry.js`）

16. `color` は `#rrggbb`（小文字）。四角・丸に限り `null`（線なし）を許し、そのときは `fill` が要る。
17. `fill`（新）は四角・丸だけが持つ。`#rrggbb` か `null` で、無いものは `null` として扱う。
18. `lineStyle`（新）は、四角・丸が `'solid'`・`'dashed'`・`'cloudy'`、直線・矢印が `'solid'`・`'dashed'`。無いものは `'solid'`。
    〔H〕読み込んだ破線の間隔・雲形の強さ・`/RD` を持ち回る欄。
19. `lineWidth` は正の数。画面から入るのは 1〜40 の整数。線なしでも持つ（線を戻したときの太さ）。
20. `opacity` は 0 より大きく 1 以下。画面から入るのは 0.1〜1（小数 2 桁）。
21. `validEntry`・`copyEntry`・`sameEntry`・`PATCH_FIELDS`（`fill`・`lineStyle` を足す）・`validPatchValue`・`toSaveEntry` を広げる。
    `annotation-state.js` の `updateAnnot` は、変えた後の形を `validEntry` で確かめ、崩れるなら何もしない（線なしのまま塗りを
    なしにする、など）。

### E. 設定（`annotation-settings.js`。①-a で `settings.js` から移したもの）

22. `annotColors`: 道具ごとの最後の色。`#rrggbb` なら何でも受ける。既定は確定事項14。
23. `annotFills`（新）: `{ shape: '#rrggbb' | null }`。既定 `null`。
24. `annotStrokeNone`（新）: `{ shape: boolean }`。既定 `false`。塗りが `null` なら `false` として扱う。
25. `annotLineStyles`（新）: `{ shape: 'solid' | 'dashed' | 'cloudy' }`。既定 `'solid'`。直線・矢印の道具では、雲形は実線として扱う。
26. `annotLineWidth`: 1〜40 の整数。既定 2（論点4）。
27. `annotOpacity`: 道具ごとに 0.1〜1。既定 1。
28. 道具を替えても色・塗り・線種・太さは既定に戻さない（道具ごとに最後の値を覚える。論点6。決定33 ⑥ のまま）。

### F. 保存（ワーカー）

29. 四角・丸: 線があれば線幅の半分だけ内側の path に線を引き、塗りがあれば同じ path を塗る（`B`・`f`・`S`）。線なしなら箱そのものを
    塗る（`f`）。
30. 太い線: 描く線幅は、四角・丸の短い辺の半分で頭打ちにする（そのとき線が箱をすべて覆う）。`/BS /W` には選んだ太さを書き、開き直すと
    選んだ太さに戻る。画面と印刷も同じ式で描く（`shape-geometry.js` と `worker/shape-appearance.js` の一致をテストで見張る）。
31. 不透明度が 1 未満の図形・ペンは、外観を透明グループで包む。外観の中身は `q /GS gs /G0 Do Q` で、`G0` は
    `/Group << /S /Transparency >>` の Form にして中は不透明で描く。塗りと線、矢印の軸と矢じり、ペンの線どうしが重なっても濃くならない
    （事前調査 D）。1 のときは今のまま。テキスト・ノート・マークアップも今のまま。
32. 破線: `/BS << /W 線幅 /S /D /D [間隔] >>` と、外観の `d`。間隔は 1 種類で、線の太さに比例させる（決定47）。〔H〕式を決める。
33. 〔H〕雲形: `/BE << /S /C /I 強さ >>` と外観の弧、`/RD` と `/Rect` の取り方。
34. 辞書: `/C` は線があるときだけ、`/IC` は塗りがあるときだけ書く。`/BS << /W 線幅 /S /S >>`（線なしは `/W 0`）、`/Border [0 0 線幅]`
    （線なしは `[0 0 0]`）、`/CA`。
35. 保存の形: 四角・丸は `{ src, kind, color | null, fill | null, lineStyle, opacity, rect, lineWidth }`、直線・矢印は `lineStyle` を足す。
    〔H〕雲形と読み込んだ破線の欄。

### G. 読み戻し（①-a の口の答えの当て方を広げる）

36. `interior` → `fill`（四角・丸）。`/C` が無いか空、または線幅 0 の四角・丸は、塗りがあれば `color: null`（線なし）にする。塗りも線も
    無いものは表示のみのまま。
37. 破線（`borderStyle.style` が破線、または口の `borderStyle` が `'D'`）は `lineStyle: 'dashed'`。〔H〕元の `/D` を持ち回るか。
38. 〔H〕雲形・`/RD`。
39. 灰（1 成分）と CMYK（4 成分）の色は RGB に直す（灰は同じ値、CMYK は 1 − min(1, c + k) などの素朴な式）。

### H. 印刷

40. 印刷の描き手（`shape-graphics.paint`）は、不透明度が 1 未満のとき、別の canvas に不透明で描いてから alpha で重ねる（確定事項31 と
    同じ見え方。事前調査 D）。塗り・線なし・破線・雲形も描く。

## 起草者の判断で決めたもの

- 線と塗りの「なし」はパレットの下の段に置き、チップでは白地に赤の斜線で示す（モック）。
- 既定の色の対応は色差でいちばん近いパレットの色にした（確定事項14・15）。桃は近い色が無いのでそのまま。
- 移し替えは 1 回だけにし、済んだ印を設定に書く（その後に自分で同じ値を選んでも、置き換えない）。
- 線幅の頭打ち（確定事項30）と、透明グループを不透明度 1 未満に限ること（確定事項31）。
- パレットの色の読み上げ名は値（`#RRGGBB`）にする。
- スライダーの刻みは 1（数値欄と同じにして、つまみの位置と数字が食い違わないように）。
