## 目的

ユーザーの依頼（2026-11-20）による。

> * 多角形の頂点選択時に右クリックすると、これまでの頂点選択ごとすべてキャンセルされてしまうのですが、1回の選択だけキャンセルされるようにしてほしいです
> * 多角形、四角形、丸など、塗りつぶしができる図形は、斜線等のハッチングができる機能がほしいです
> * 多角形、四角形、丸など、塗りつぶしができる図形で塗りつぶし設定をすると枠線も含めて設定されてしまいます。塗りつぶし等の設定を枠線と内側で分けられるようにしたいです。
> * 丸を描画する機能では正円を描けるようにしたいので、縦横比を設定できる機能を追加してください
> * なんの機能も選択していない時はプロパティ欄（右サイドバー）は閉じている状態にしてください。

続けて、マーキング機能の依頼（2026-11-20。外の円の線と中の円の塗りの、赤い図の画像付き）。

> マーキング機能として添付の画像のような図形を配置できるきのうを追加してください。
> * これらの丸はいずれも正円です。
> * 白で塗りつぶしではなく、透過します。
> * 他にもマーキング図形のバリエーションが欲しいのでアイデアをいくつか提示してください。
> * このマーキングはサイズ変更もできるようにしたいです。外の円の大きさと中の円の大きさを独立して変更できるようにしてください
> * 色も変更できるようにしたいです。

## 確定事項

### A. 多角形の右クリック（決定100 ①）

- A1. 多角形の頂点を置いている途中に右クリックすると、最後に置いた頂点を 1 つだけ取り消す。残った頂点とカーソルまでの次の辺の下見はそのまま。
- A2. 頂点が 1 つの時に右クリックすると、描画をやめる（今までの右クリックと同じ）。
- A3. 右クリックのメニューは、今までどおり表示しない。Esc・左＋右・Ctrl+Z／Ctrl+Y は、今までどおりすべての頂点を捨てる。
- A4. ヒント文言を「右クリックで最後の頂点を取り消し、Esc でキャンセルします」の意味に変更する。

### B. 枠線と塗りの分割（決定100 ②⑦）

- B1. 四角・丸・閉じた多角形のプロパティパネルを、見出し「枠線」（線の色・線種・線の太さ・透明度）と見出し「塗り」（塗りつぶし・透明度・ハッチング・ハッチング色・ハッチング間隔・ハッチング線幅）に分ける。塗りの透明度は塗りつぶしの行のすぐ下に置く（質問 NM1）。
- B2. 書き込みのデータに、塗りの不透明度 `fillOpacity`（0.1〜1）を追加する。今までの `opacity` は枠線の不透明度として残す。`fillOpacity` が無い書き込み（今までのファイル・データ）は、`opacity` と同じ値として扱う。
- B3. 画面に表示する名前は「透明度」で、値は 100 − 不透明度 × 100（0〜90%）。テキスト・ペン・マーカー・ノートなど、ほかの書き込みの「不透明度」の行も、名前と向きを同じに変更する（質問 NM1。向きは Claude の解釈）。
- B4. 塗りの透明度は塗りつぶしだけに効く。ハッチングの線は透けない（Claude の解釈。質問 NM1 で、透明度バーの位置が塗りつぶしの行の下と決まったため）。
- B5. 枠線と塗りを別の透明度で描く時は、塗りを線の内側の縁までに限り、重なる帯が濃くならないようにする（`spec-4b-1b` 事前調査 D の v3）。

### C. ハッチング（決定100 ③）

- C1. 種類は、なし・斜線・逆斜線・交差斜線・横線・縦線・格子の 7 つ（なしを含む）。
- C2. ハッチング色は、塗りつぶしの色と別に持つ。背景は塗りつぶしの設定で決まる（塗りつぶしなしなら透過）。
- C3. ハッチング間隔とハッチング線幅は、数値（pt）で入力する。
- C4. 閉じた図形（四角・丸・閉じた多角形）だけに付けられる。

### D. 大きさと縦横比（決定100 ④）

- D1. 四角・丸・×印を選択した時、プロパティパネルに大きさ（幅・高さ。pt）の数値欄と、「縦横比を固定」のチェック欄を表示する。
- D2. 「縦横比を固定」にチェックがある時は、ハンドルでも数値でも縦横比を保って大きさを変える。新しく描く四角・丸・×印は、正方形・正円になる。
- D3. チェックの状態は、アプリが記憶する（次に起動した時も同じ）。

### E. プロパティパネルの開閉（決定100 ⑤）

- E1. 編集モードで、プロパティパネルに表示する設定がある時（書き込みツールを選択した時・書き込みを選択した時・トリミングとモザイクの時）だけ開く。それ以外（書き込みツールなし、［選択］［ハンド］で書き込みを選択していない時）は閉じる（質問 SH4「案A 設定表示時開閉（推奨）」）。
- E2. 開閉すると、ページの表示域の幅が 260px 変わる。倍率が［幅］［全体］の時は、倍率を計算し直す。

### F. マーキング（決定100 ⑥）

- F1. 編集ツールバーの多角形の右に、書き込みツール「マーキング」を追加する。
- F2. 形は 5 種: ご依頼の形（外の円の線と中の円の塗り）・二重丸（外の円と中の円がどちらも線）・照準（外の円と十字線）・番号付き丸（円の中に番号。配置するたびに 1・2・3…と増える）・注意マーク（三角形と「！」）。プロパティパネルの「形」の行で選ぶ。
- F3. ページをクリックすると、クリックした位置を中心に配置する。外の円と中の円はどちらも正円で、中は透過する。
- F4. 外の円と中の円の大きさは、ページ上のハンドル（外の円の上下左右の四角 4 つ、中の円の右の丸 1 つ）と、プロパティパネルの「外の円の直径」「中の円の直径」（pt）で、別々に変更する。照準は中の円の代わりに十字線の長さ、番号付き丸は番号の文字サイズを変更する。注意マークは大きさ 1 つ。
- F5. 色・線の太さ・透明度を変更できる。
- F6. 保存すると、PDF の標準の注釈（外観付き）にする。ほかのアプリでも同じ見た目で表示される。

## 実装の記録

### B・C 枠線と塗りの分割・ハッチング（2026-11-20）

**データの形**（`renderer/fill-style.js`。ワーカーは `worker/fill-style-rules.js`。一致はテストで見張る）

- `fillOpacity`: 塗りつぶしの不透明度。0 より大きく 1 以下（画面から入るのは 0.1〜1）。持たない書き込みは `opacity` と同じ値として扱う。
  `opacity` は枠線の不透明度。
- `hatch`: `{ pattern, color, gap, width }`。`pattern` は `'diagonal'`（斜線）・`'reverse'`（逆斜線）・`'cross'`（交差斜線）・`'horizontal'`（横線）・
  `'vertical'`（縦線）・`'grid'`（格子）。なしは欄を持たない（`null` を当てると欄を削除する）。
- どちらも塗りを持てる書き込み（四角・丸・閉じた多角形。`shapeStyle.canFill`）だけが持てる。変更できる欄（`PATCH_FIELDS`）に追加した。
- 枠線の透明度を変える時、`fillOpacity` を持たない書き込みには今の `opacity` を `fillOpacity` として残す（`fillStyle.keepFillOpacity`）。
  今までの書き込みで枠線の透明度だけを変えても、塗りつぶしの見た目は変わらない。

**数値の範囲と既定**（Claude の判断）

| 項目 | 範囲 | 既定 | 入力 |
|---|---|---|---|
| 塗りの透明度 | 0〜90%（不透明度 0.1〜1） | 0% | スライダーと数値欄（枠線の透明度と同じ部品） |
| ハッチング間隔 | 1〜50pt | 6pt | 数値欄（矢印は 0.5 刻み。小数も入力できる） |
| ハッチング線幅 | 0.25〜10pt | 1pt | 数値欄（矢印は 0.25 刻み） |
| ハッチング色 | `#rrggbb` | `#ff0000`（図形の線の色の既定と同じ） | 線の色と同じ分割ボタンと色の一覧（直前の色は線の色と共通の `line`） |

範囲の外と読めない値は当てずに、数値欄を今の値へ戻す。大きな図形に細かい間隔を付けた時は、1 方向の線を 2,000 本までにするよう間隔を広げる
（`LINES_MAX`。描く量と外観の大きさを抑えるため）。

**次に追加する書き込みの値**（`renderer/annotate-fill.js`）

- settings.json の `annotFillOpacity: { shape: 0.1〜1 }` と `annotHatch: { shape: { pattern: 'none' か種類, color, gap, width } }`
  （`annotation-fill-settings.js`。既定は `{ shape: 1 }` と `{ shape: { pattern: 'none', color: '#ff0000', gap: 6, width: 1 } }`）。
  ハッチングがなしでも、色・間隔・線幅は記憶し、次にハッチングを選択した時に使う。今がなしの書き込みに種類を当てる時も、この記憶の色・間隔・線幅を使う。
- 新しく描く四角・丸（`shape-draft.js`）と、閉じて確定した多角形（`annotate-polygon.js`）に付ける。`fillOpacity` は枠線と違う時だけ、
  `hatch` はある時だけ持たせる。

**プロパティパネル**（`renderer/annotation-fill-rows.js`。`index.html` の `#props-stroke-head`・`#props-fill-head` と塗りの行）

- 見出しは、表示している相手に塗りを持てるものがあり、テキストが無い時に表示する（`viewOf` の `split`）。複数選択で直線と四角が混ざる時も
  見出しを付け、塗りの行は四角にだけ当てる。テキストと四角が混ざる時は見出しを付けず、塗りの透明度とハッチングの行も表示しない（Claude の判断）。
- 塗りつぶしの行は、見出しを付ける時だけ塗りの見出しのすぐ下へ DOM の中で移し、付けない時は元の位置（書式の行の次）へ戻す。
- 行名「塗り」は、テキストを含めてすべて「塗りつぶし」に変更した（色の一覧の題名・ツールチップ・ヒント文言も同じ。Claude の判断。
  「塗り」は見出しの名前なので、1 つの用語で 2 つのものを指さないように）。
- ハッチング色・ハッチング間隔・ハッチング線幅の行は、ハッチングがある時だけ表示する（Claude の判断。なしの時は種類の一覧だけ）。
  種類は `<select>`（なし・斜線・逆斜線・交差斜線・横線・縦線・格子。複数選択でそろっていなければ空の「混在」）。
- 履歴は 1 世代ずつ。同じ欄を続けて変えたら 1 世代に畳む今の決まりで、ハッチングは種類・色・間隔・線幅を別の欄として扱う
  （種類を選択してから間隔を変えた時に、Ctrl+Z で間隔だけが戻る）。

**画面と印刷**（`renderer/fill-apart-graphics.js`・`renderer/hatch-geometry.js`）

- 分けて描くのは、ハッチングがある時か、塗りつぶしがあり `fillOpacity` が `opacity` と違う時（`fillStyle.paintsApart`）。それ以外は、
  今までどおり `<g opacity>`（印刷は別の canvas と `globalAlpha`）で図形全体を薄める。塗りつぶしもハッチングも無い図形は、内側に描くものが
  無いので、塗りの透明度が違っても今までどおり（見た目は同じ）。
- 分けて描く時の順序: 塗りつぶし（塗りの不透明度）→ ハッチング（不透明。図形の形で切り抜く）→ 枠線（枠線の不透明度）。
- 枠線があり半透明の時は、塗りつぶしとハッチングの層から枠線の帯を抜く（画面は SVG の `mask`〔白で塗った図形から黒で枠線を引く〕、
  印刷は別の canvas に描いて `destination-out`）。塗りは線の内側の縁までになり、線と塗りの重なる帯は濃くならない（B5）。枠線が不透明な時は
  枠線が帯を覆うので抜かない。線なしの時は今までどおり箱そのもの（雲形は雲の形）を塗る。
- ハッチングの線は、回す前の箱（四角・丸は `rect`、多角形は頂点の外接）の中心を通る 1 本を基準に、間隔ごとに並べる。向きは紙の座標
  （y が上）で、斜線は右上がり 45°。回した図形は `<g>` の回転の中に描くので、図形と一緒に回る。

**保存の外観**（`worker/fill-apart-appearance.js`。四角・丸の path の命令は `worker/box-path-ops.js` へ移した）

```
/SigKStyle /SK BDC
q /GF gs                          … GF: /ca 塗りの不透明度 /CA 1（枠線が半透明なら /SMask 輝度）
<塗りつぶしの色> rg <path> f
q <path> W n <ハッチング色> RG <線幅> w 0 J 0 j [] 0 d <線…> S Q
Q
q /GL gs <線の色> RG <線の太さ・破線・角> <path> S Q   … GL: /CA /ca 枠線の不透明度
EMC
```

- 分ける条件は画面と同じ（ワーカーの `isApart`）。それ以外の図形は、今までどおり透明グループと辞書の `/CA` で書く（今までのファイルと同じ）。
  塗りつぶしもハッチングも無い図形の `fillOpacity` は、保存すると失われる（読み戻すと `opacity` と同じ値になる。見た目は変わらない）。
- `<path>` は塗り・切り抜き・枠線で同じもの（線があれば線幅の半分だけ内側の四角・楕円、雲形は雲の path、多角形は頂点を h で閉じたもの）。
  雲形はハッチングを雲の形の内側で切り抜く（C4 の第一案）。
- SMask は `/S /Luminosity` で、`/G` は `/Group << /S /Transparency /CS /DeviceGray >>` の Form（中身は `1 g <path> f 0 G <線の命令> <path> S`）。
- 外観が不透明度を持つので、辞書の `/CA` は 1 にする。
- 回した図形は今までどおり外側の Form の `/Matrix` で回す（SMask の Form も同じ座標で描かれる）。フラット化は外観をそのまま焼き込み、
  ExtGState と SMask も一緒に残ることをテストで確かめた。

**マーク付き内容の名前と形（読み戻し）**

  見える（Claude の判断。PDF の外観はページの回転と一緒に回る決まりのため）。
- Acrobat など、ほかのアプリでの見え方（SMask の解釈）。

### D 大きさと縦横比（2026-11-20）

**プロパティパネル**（`renderer/annotation-size-row.js`。`index.html` の `#props-box-size-row`・`#props-keep-ratio-row`）

- 回転の行のすぐ上（見出し「枠線」「塗り」の外）に、行「大きさ」（「幅 [数値] pt　高さ [数値] pt」の 1 行）と、チェック欄「縦横比を固定」を置く。
  チェック欄は設定画面と同じ `.print-choice`（`accent-color`）。
- 四角・丸・×印を 1 件選択している時（表示のみを除く）は両方、四角・丸・×印の書き込みツールを選択している時はチェック欄だけを表示する。
  複数選択・トリミング・モザイク・ほかの書き込みでは両方を隠す（複数選択でチェック欄も隠すのは Claude の判断。複数選択ではハンドルが無く、
  チェックが効く操作が無いため）。
- 幅と高さは、回す前の箱（`entry.rect`）の幅と高さ。表示は小数 1 桁（`shapeSize.shownOf`）。
- 数値欄は Enter・フォーカスを外す（change）で確定し、`annotateTransform.commit` で 1 世代積む（Ctrl+Z で戻る）。Esc は打ちかけを捨てて
  今の値へ戻す（`field-escape.js`）。打ちかけの値は、打ち始めた時の相手にだけ当てる（文字サイズの欄と同じ）。

**数値の範囲と計算**（`renderer/shape-size.js`。Claude の判断）

| 項目 | 内容 |
|---|---|
| 範囲 | 1〜14400pt（最小はハンドルの最小 `shapeGeometry.MIN_SIDE` と同じ。最大は PDF のページの大きさの上限 200 インチ） |
| 範囲の外・数でない値・空 | 当てずに、数値欄を今の値へ戻す |
| 縦横比を固定で、もう一方が範囲の外になる値 | 当てない（例 200×100 の図形の高さに 0.8 を入力すると、幅が 1.6・高さが 0.8 になり最小を下回る） |
| 位置 | 箱の中心を保つ。回した図形も、回転の中心（箱の中心）が動かないので、紙の上の位置はそのまま |
| 丸め | 入力値は小数 2 桁に丸める（ほかの形の計算と同じ） |

**縦横比を固定**（`renderer/shape-ratio.js`）

- 状態は四角・丸・×印で共通の 1 つ。settings.json の `annotKeepRatio`（真偽値・既定 false。`annotation-ratio-settings.js`）に記憶し、
  起動時に `app.js` が `shapeRatio.apply` で戻す。チェックを変えた時だけ記憶する。
- チェックがある時の動き:
  - 数値欄: 幅を入力すると高さを、高さを入力すると幅を、今の縦横比で変える。
  - 角のハンドル: Shift なしでも縦横比を保つ（`shapeResize.resized` の `keep`。計算は今までの角＋Shift と同じ）。
  - 辺のハンドル: 掴んだ向きの伸び縮みと同じ比で、もう一方の向きを箱の中心から両側へ伸ばす。掴んだ辺の反対の辺は動かない（Claude の判断。
    右の辺を右へ引くと、左の辺はそのままで、上下が同じだけ伸びる）。どちらの向きも最小 1pt より小さくしない。回した図形も、
    今までどおり回す前の座標で計算して中心を回して戻す。
  - 新しく描く四角・丸・×印: Shift なしでも正方形・正円（×印は縦と横が同じ長さ）になる（`shapeDraft.begin` の `keep`）。
  - チェックが無い時は今までどおり（角＋Shift だけが縦横比を保ち、辺＋Shift は何もしない）。
- 多角形・直線・矢印・ペン・テキスト・ノートには効かない（`shapeRatio.keepsFor` が四角・丸・×印の時だけ true）。

**ヒントと使い方画面**

- 選択時のヒント `boxTransform` の後ろに、大きさの欄と縦横比を固定の説明を追加した。今までの説明（角は Shift で縦横比を保つ）は残した。
- 四角・丸・×印の書き込みツールのヒントに `boxRatio`（「縦横比を固定」にチェックを入れると、Shift なしでも正方形・正円になる）を追加した。
  `shape` は直線・矢印と共通なので、`shape` の文言は変更していない。
- 使い方画面（`help-content-edit.js`）の「描画後の変形（白いハンドル）」に、大きさの欄と縦横比を固定の 2 項目を追加した。

**確かめていないこと**

- 起動して画面を目で見る確認（行の見た目・プロパティパネルの幅 260px に 1 行で収まるか・チェック欄の見た目）はしていない。テストは jsdom で、
  行の出し入れ・数値の確定・ハンドルのドラッグ・記憶まで。
- Chromium で数値欄に Enter を押した時に change も発生する場合は、2 回目の確定は同じ大きさなので積まない（テストでは確かめていない）。
