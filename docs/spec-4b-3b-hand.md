## 目的

編集モードで、**CheckListMaker の画像エディタと同じく、マウスの左右のボタンとホイールだけで表示と道具を行き来できる**ようにする。

- 道具の段の「選択」の隣に**「ハンド」**の道具を置く。持っている間は、紙のどこを左で押して引いても表示が動く（書き込みは選ばない）。
- **書き込みの上で右クリックすると「削除」のメニュー**が出る。選んでいなければ、その書き込みだけを選んでから出す。
- **左を押したまま右を押す（左＋右）**と、進んでいる操作（描きかけ・置く前・範囲選択・掴んで動かす・つまみ・文字をなぞる・表示を引く）を
  取りやめて道具を切り替える（道具なし・選択・描く道具 → ハンド、ハンド → 戻り先）。何も置かれない。
- **ホイールで拡大・縮小**する。ハンドのときは素のホイール、閲覧モードと編集モードではどの道具でも Ctrl＋ホイール。1 目盛りで
  ツールバーの「＋」「－」と同じ 1 段。マウスの下の紙の場所は動かない。ノートパソコンのタッチパッドの 2 本指の広げる・狭めるも同じ（決定55）。

## 事前調査

`docs/spec-4b-3a-selection.md` の事前調査 A（右クリックの順）・B（左を押したまま右を押す）・F（ホイール）を引く。要点は次のとおり。

- **A** 右クリックは mousedown（button 2・buttons 2）→ selectstart → mouseup（buttons 0）→ auxclick → **contextmenu（離した後）**。Electron の
  `context-menu` は来るが、アプリにメニューの処理が無いので何も出ない。文字を選んだまま別の文字の上を右で押すと、その選択が消える。
- **B** 左でなぞっている途中に右を押すと mousedown（button 2・**buttons 3**）。右を離すと mouseup（button 2・buttons 1）→ contextmenu（左はまだ押したまま）。
  右の mousedown で `removeAllRanges` するだけでは、動かすと文字の選択がまた伸びる。**右の mousedown を preventDefault ＋ removeAllRanges ＋ 全部の
  ボタンを離すまで selectstart を preventDefault ＋ 左で動かすたびに removeAllRanges** で 0 字のまま。contextmenu を preventDefault すれば Electron の
  `context-menu` も来ない。右の mousedown を preventDefault すれば、今ある文字の選択は残る。左を押したまま右を 2 回押すと 2 回とも届く。
  右が先で左が後でも mousedown（button 0・buttons 3）→ … → click（button 0）が届く。
- **F** 素のホイールは `#view` を 120px 送る。**Ctrl＋ホイールは今は何も起きない**（スクロールせず、webContents の倍率も表示倍率も変わらない）。

③-b のセッションでコードを読んで分かったこと（2026-10-01）:

- **G 描き直しの間引き**: 倍率を変えると、`viewer.setZoom` が世代番号を進めて飛んでいる描画を捨て、描き直しは `page-render.js` の
  `scheduleUpdate` が 1 フレームに 1 回へまとめる。ホイールを速く回して 1 フレームに何段も変わっても、描くのは最後の倍率だけになる。
  → ③-b で間引きは足さない。
- **H 拡大で先頭へ戻る**: 今の `viewer.setZoom` は、倍率が変わると `goToPage(state.current)` で今のページの先頭へ送る（`viewer.js` の setZoom）。
  マウスの下の紙の場所を保つ口が要る（確定事項C4）。`#view-pages` は `margin:0 auto` で横に中央寄せなので、紙の位置は描き直した後の
  `#view-pages` の位置から測る。
- **I 描きかけの取りやめ**: Esc は `annotateShape.cancelDraft()` で下書きを捨てるが、`annotate-draw.js` の「描いている」印は残り、離したときに
  `finishDraft` が空振りする。左＋右では印ごと捨てる口（`annotateDraw.cancel()`）が要る。
- **J タッチパッドの 2 本指**: Windows の高精度タッチパッドの広げる・狭めるは、Chromium が **ctrlKey 付きの wheel**（deltaY は 1 回あたり数〜十数の
  小さな値で、細かく何回も届く）としてページへ渡す。Electron は画面そのものの拡大（visual zoom）を既定で止めているので、今は何も起きない。
  マウスの 1 目盛りは deltaY が 100 前後（表示の拡大率で 100〜150）で 1 回届く。
- **K 入力欄を閉じた右の押し**: `free-text-editor.js` は、入力欄の外を押すと（右でも）確定して swallow を立て、`#view` の mousedown で pointer が
  それを取る。swallow は mouseup（捕捉）で消えるので、離した後に届く contextmenu の時点ではもう消えている。→ 右ボタン側で、押したときに
  飲んだことを覚えておく（確定事項D6）。

## 確定事項

### A. ハンド（`renderer/annotate-hand.js`・`annotate-tools.js`・`edit-bar.js`）

1. 道具の段の「選択」と区切りの間に**「ハンド」**のボタンを置く（モック `screenshots/phase4b-3-bar.png`・`phase4b-3-menu.png`）。アイコンは手の形の
   インライン SVG（`assets/icons.js` に `hand` を足す。見本と同じ形）。名前は「ハンド」。編集モードの段にだけある。
2. 道具の名前は `hand`。`POINTER_TOOLS = ['select', 'hand']`（`annotate-tools.js`）。`drawingTool()` は null を返すので、右パネルは描く道具の欄を出さない。
3. **ハンドのとき、`#view` の中を左で押すと、どこでも（紙の上でも、灰色の所でも、書き込みの上でも）表示を引き始める**。引いた分だけ `#view` の
   スクロールを逆に動かす（手で紙を引く向き）。押した mousedown は preventDefault（文字を選ばせない）。`#view` のスクロールバーの上は除く。
   - 引いている間は `html[data-panning]` を付け、カーソルを grabbing にする。持っているだけのときは grab。
   - 動きは前回の点からの差で足していく（引いている途中で倍率が変わっても飛ばない）。
   - 離したら（左を離した・左＋右・Esc・道具が替わった）終える。表示は引いたところに残る。
4. ハンドのときは、**左ボタンでは書き込みを見ない**: 当たり・つまみ・ダブルクリック（テキストを直す）・つまみの上のカーソルを見ない。押して離しても
   選択は変えない。**右ボタンは書き込みを見る**（D）。
5. ハンドのときは紙の文字の層を選べなくする（`html[data-tool="hand"]` で `user-select:none`。「選択」の道具と同じ書き方）。
6. 右パネルのヒント（何も選んでいないとき）: 「紙を引くと表示が動きます。ホイールで拡大・縮小します。書き込みの上で右クリックすると削除できます。
   もう一度押すか Esc で道具を外します。」

### B. 道具の行き来（`renderer/tool-switch.js`・`annotate-tools.js`。モック `phase4b-3-tools.png`。決定53 ⑥）

N＝道具なし、S＝選択、H＝ハンド、D＝描く道具（マークアップ・テキスト・図形・ペン・ノート）。**道具を切り替えるのは、左＋右・道具のボタン・Esc だけ。
紙の空白の右クリックでは切り替えない。**

| 今 | 紙の空白で右クリック | 書き込みの上で右クリック | 左＋右 | 同じボタンをもう一度 | Esc |
|---|---|---|---|---|---|
| N | 何もしない | 削除のメニュー | 取りやめて H | — | 選択を外す |
| S | 何もしない | 削除のメニュー | 取りやめて H | N | 選択を外す → N |
| H | 何もしない | 削除のメニュー（道具は H のまま） | パンを終えて戻り先 | N | 選択を外す → N |
| D | 何もしない | 削除のメニュー | 取りやめて H | N | 描きかけ・入力欄・選択を順に閉じ、最後に N |

1. **戻り先**は、最後に持っていた「道具なし」か「選択」（既定は道具なし）。道具が N か S になるたびに覚え直す。H・D になっても変えない。
2. 判断は純関数 `toolSwitch.next({ tool, base }, via, pressed)` に置く（via は `chord`・`button`・`escape`。pressed は押したボタンの道具）。
   返すのは次の `{ tool, base }`。`annotate-tools.js` は戻り先を持ち、`setTool` のたびに `toolSwitch.remember` で覚え直す。
3. 道具のボタンは今のまま（同じボタンでもう一度押すと N、別のボタンならその道具。マークアップは選んでいる文字があればその場で付ける）。
4. 左＋右は E の取りやめのあとで切り替える。H からの左＋右は戻り先へ、ほかからは H へ。

### C. ホイールの拡大・縮小（`renderer/wheel-zoom.js`・`viewer-wheel.js`・`zoom-anchor.js`・`viewer.js`。決定53 ⑧⑪⑫・決定55）

1. **ハンドのときは、Ctrl を押さないホイールでも拡大・縮小する。閲覧モードと編集モードでは、どの道具でも Ctrl＋ホイールで拡大・縮小する。**
   ページ編集モードとツールモードは対象外（今のまま）。文書が開いていなければ何もしない。上へ回すと拡大、下へ回すと縮小。
2. **1 目盛りで、ツールバーの「＋」「－」と同じ刻み（`viewer-layout.js` の `ZOOM_STEPS`）を 1 段**。最大・最小に達したらそれ以上は変えない。
   倍率を変えたら「幅」「全体」の追従は外れる（「＋」「－」と同じ）。
3. **回した量を溜めて、50 を超えたら 1 段**にする（deltaY。deltaMode が行なら 40 倍、ページなら 800 倍して px に揃える）。マウスの 1 目盛り（100 前後）は
   1 回で 1 段になり、タッチパッドの細かい量は溜まってから 1 段になる（決定55）。1 段進めたら溜めた量は 0 に戻す（余りを持ち越さない。表示の拡大率で
   1 目盛りが 125 になっても 1 段のまま）。向きが変わったとき・前の回転から 250ms 空いたときも 0 から溜め直す。1 回のイベントで進めるのは 1 段まで。
4. **マウスの下の紙の場所を動かさない**。`viewer.setZoom(zoom, { anchor: { clientX, clientY } })` を足す。
   - 倍率を変える前に、マウスの点が乗っているページ（乗っていなければ一番近いページ）と、その中の割合を控える（純関数 `zoomAnchor.capture`）。
   - 並べ直した後で、同じページの同じ割合の点（`zoomAnchor.place`）がマウスの下に来るように `#view` の scrollLeft・scrollTop を動かす。
     端で動かせない分は寄せられるところまで。
   - anchor を渡さないとき（「＋」「－」・キー・「幅」「全体」）は今のまま（ページの先頭へ送る）。
5. 拡大・縮小するときは `wheel` を preventDefault する（`{ passive: false }` で結ぶ。そうしないと止められない）。拡大・縮小しないホイールは今のまま
   （#view を送る）。縦の量が 0 のホイール（横だけ）は、ハンドのときも拡大・縮小せずに今のまま送る。
6. 描き直しの間引きは足さない（事前調査 G）。

### D. 右クリックと「削除」のメニュー（`renderer/annotate-right-button.js`・`annotation-menu.js`。モック `phase4b-3-menu.png`）

1. 編集モードで文書が開いているとき、`#view` の右の mousedown は preventDefault する（今ある文字の選択を消さないため。事前調査 B）。
   右の押し離しでは描かない・置かない・掴まない・選ばない（③-a の確定事項B1 のまま）。メニューを出すかどうかは、離した後に届く contextmenu で決める。
2. contextmenu は、編集モードで文書が開いていれば preventDefault する（Electron の `context-menu` を出さない）。閲覧・ページ編集・ツールのモードは今のまま。
3. **書き込みの上**（`annotate.hitTest` に当たる。どの道具でも、ハンドのときも）なら:
   - 選んでいなければ、それだけを選んで枠を見せてから、メニューを出す。
   - 選んでいれば（複数選択の 1 件を含む）、選択はそのままでメニューを出す。「削除」は選んでいる全部を消す（`annotate.remove()`。1 世代）。
   - **選んでいる書き込みの枠の中**（枠の余白を含む。一覧で選んだ表示のみの書き込みも）も当たりにする（枠が見えているので、消せる）。
4. **紙の空白・紙の外なら何もしない**（開いているメニューは閉じる）。道具は替えない（決定53 ⑥）。
5. テキストの入力欄の上では何もしない（入力欄のものにする）。
6. **入力欄を閉じた右の押しのあとに届いた contextmenu は飲む**（その押しは入力欄を閉じるためのもの。事前調査 K）。
7. メニュー（`index.html` の `#annot-menu`。role=menu）は、項目が 1 つ: ごみ箱のアイコン・「削除」・右に薄い字で「Delete」。押した点に
   position:fixed で出す。窓の端からはみ出すときは純関数 `annotationMenu.placeAt` で内側へ押し戻す（端から 4px 空ける）。
8. メニューを閉じるきっかけ: 項目を押した・メニューの外の mousedown（捕捉で見る）・Esc（`annotate.escape()` の先頭）・ほかのキー（Esc 以外。Delete は
   閉じてから消す）・`#view` のスクロール・ホイール・窓の大きさの変更・窓のフォーカスが外れた・モードの切り替え・選択の変化・左＋右。
9. **メニューの外を左で押して閉じたとき、その押しが `#view` の中なら飲む**（描き始めない・置かない・選ばない。入力欄を閉じた押しと同じ扱い）。
   右で押して閉じたときは飲まない（そのまま別の書き込みの上なら、そこでメニューが出る）。
10. メニューにフォーカスは移さない（キーボードの Enter が右パネルの「直す」に流れないため）。キーで消すときは Delete。

### E. 左＋右（`annotate-right-button.js`・`annotate-pointer.js`。決定53 ④）

1. **編集モードで文書が開いていて、`#view` の中で左と右の両方が押された時点**（mousedown の buttons が 1 と 2 を両方含む）で効かせる。左が先でも
   右が先でも同じ（事前調査 B）。テキストの入力欄の中は除く。
2. 効いたら、次を順に行う。
   1. 進んでいる操作を全部取りやめる: 描きかけ（`annotateDraw.cancel()`。下書きを捨てる）・テキスト／ノートの置く前の押下（`annotatePress.reset()`）・
      範囲選択（押す前の選択に戻す）・掴んで動かす（写しを捨てて元の位置）・つまみ（元の形）・表示を引く（そこで終える）・文字の選択（`removeAllRanges`）・メニュー。
   2. B の表で道具を切り替える。
   3. **全部のボタンを離すまで**: mousemove・mouseup を捨て（pointer は何もしない）、selectstart を preventDefault し、左で動かすたびに文字の選択を外す。
      全部のボタンが離れた mouseup（buttons 0）で解く。保険として、buttons 0 の mousemove・窓のフォーカスが外れたときも解く。
   4. 押した mousedown は preventDefault する。
3. **左を押したまま右を何度押しても、切り替えは 1 回だけ**（全部のボタンを離すまで、次の左＋右を見ない。事前調査 B）。
4. 左＋右の後 **1000ms 以内に届いた contextmenu は捨てる**（メニューを出さない）。全部のボタンを離すまでに届いたものも捨てる。
5. 左＋右の後、左を離しても何も置かれない・作られない（マークアップも作らない）。

### F. 押しの振り分け（`annotate-pointer.js` の新しい順）

押したとき（`#view` の mousedown）:
1. 入力欄を閉じた押し・メニューを閉じた左の押しなら飲む（どちらの印も取る）。
2. 左＋右なら E。
3. 飲んだ押しなら、右なら D6 の印を立てて終わり。
4. 右（button 2）なら D1。中ボタンなどほかは何もしない。
5. 編集モードで文書が開いているか、入力欄の中でないか（今のまま）。
6. **ハンドなら表示を引き始める**（A3）。
7. つまみ → 押下の控え → 紙の外なら終わり → 当たり → 当たらない（③-a のまま）。

離したとき: 1 左＋右の後なら捨てる → 2 左だけ → 3 表示を引くのを終える → つまみ → 範囲選択 → 掴む → 描く の順に終える → 4 残り（③-a のまま）。
動かしたとき: 左＋右の後なら文字の選択を外して終わり → 表示を引く → つまみ → 範囲選択 → 掴む・描く → つまみの上のカーソル（ハンドのときは見ない）。

### G. Esc の順（③-b の分）

メニュー → つまみ → 範囲選択（押す前に戻す）→ 掴む（元の位置）→ 表示を引く（そこで終える）→ パレットの窓 → 下見 → 描きかけ（印ごと捨てる）→ 入力欄 →
