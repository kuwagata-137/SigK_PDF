## 目的

ユーザーの依頼（2026-11-13。印刷画面のプリンターの選択欄を開いた画面写真 1 枚付き）による。

> 一部追加の改修です。
> * プリンタ選択画面のドロップダウンの文字が真っ白で見えません。
> * 印刷ボタンがどこにあるのかわかりにくいです。開くの右側に移動してアイコンも大きくして文字も追加してください。モックイメージを提出してください
> * 編集モードのタブの「＋」ボタンをクリックしたときは、空のタブが開いて、空のタブの中央に「ファイルを開く」ボタンがあって、それをクリックするとダイアログが開くようにしてください。なお、この空のタブが開いている時かつクリップボードに画像がコピーされている時はにctrl+Vで画像が貼り付けられるようにしてください。

## 作り方

### 印刷ボタン（PB1〜PB3）

- `index.html`: `#btn-print` を `#btn-open` のすぐ後ろへ移動し、`<div class="tb-btn" id="btn-print" data-tip="bar.print" aria-disabled="true"><span data-icon="print" data-icon-size="22"></span>印刷</div>` にする（`icon` の class と aria-label を外す。文字が名前になる）。
- `renderer/shell.css`: `@media (max-width:1100px)` を PB3 の 3 段階（1340・1270・1060）に置き換える。

### 空のタブ（NT1〜NT12）

- `renderer/tabs.js`: タブに `blank: true` の種類を追加する（`{ id, path: null, name: '新しいタブ', session: null, error: null, blank: true }`）。
  `openBlankTab()`（NT1・NT5）・`isBlankActive()` を公開する。「＋」は `openBlankTab()` を呼ぶ。`restore` は空のタブなら空のタブの画面を映す。
  `openSource` は、映しているタブが空のタブなら、新しいタブを空のタブの位置に置き換える（NT4）。`list()` は空のタブを含めない
  （帯・ツール・終了の確認が使う一覧。NT10）。上限の判定（`refuseCrowded`・`count()`）は空のタブも数える。`reorder(ids)` は、空のタブを除いた
  id の並びを受け、空のタブの位置を保つ。
- `renderer/new-tab.js`（新規。`SigK.newTab`）: 空のタブの画面の表示（`sync()`。`tabs.render()` から呼ぶ）、［ファイルを開く］のクリック
  （`tabs.runOpenCommand()`）、Ctrl+V（NT6・NT7）、貼り付けた画像の名前の番号（NT8）。
- `index.html`: `#view-empty` の中に、`#newtab`（［ファイルを開く］`#newtab-open` と案内文 `#newtab-hint`）を `#view-message` と `#view-recent` の間に置く。
  `#view-empty` はクリックを通す（pointer-events:none）ので、ボタンだけ pointer-events を戻す。
- `renderer/recent-panel.js`: タブが 1 枚も無い時に加えて、空のタブを映している時も一覧を表示する（NT2）。
- メイン側: `clipboard-image.js`（新規）で `clipboard.readImage()` を PNG にし、ワーカーの `image-open`（`worker/image-open-task.js`）で
  1 画素＝1pt の PDF に組む（パスの代わりにバイト列を受けるようにする）。IPC は `clipboard:readImage`、preload は `clipboardAPI`
  （`available: true`・`readImage()`）。戻り値は画像を開く口（`image-open.js`）と同じ形で、`path: null`。画像が無ければ `{ empty: true }`。
- `renderer/viewer.js`: 名前の無い文書（`untitled`）でも、画像の欄（`image`）を捨てない。
- `renderer/save.js`・`renderer/image-save.js`: 名前の無い画像の［名前を付けて保存］（NT9）。
- `renderer/tip-content-view.js`・`renderer/help-content.js`: ツールチップ（NT11）と使い方画面。

## 試験の範囲

- 印刷ボタン: ツールバーの並び（［開く］の次が印刷ボタン、右端は検索・設定・使い方）、アイコンの大きさ 22、文字「印刷」、PB3 の CSS の規則。
- 空のタブ: 「＋」で空のタブが開く・2 回目は切り替える・上限・閉じる・Ctrl+Tab、空のタブで開いたファイルの置き換え（ダイアログ・パス・ドロップ・
  最近使ったファイル・開けなかった時・取りやめた時）、`list()` から外れる、帯にならない、最近使ったファイルの一覧の表示、Ctrl+V（画像あり・
  画像なし・入力欄にフォーカス・ツールモード）、名前の番号、名前の無い画像の保存（上書き保存がダイアログになる・既定の名前・保存後の開き直し）、
  未保存の確認、メイン側の `clipboard-image.js`（画像あり・なし・大きすぎ）とワーカーのバイト列の入口。
- 試験はユーザーのクリップボードに触れない（NT12）。

## 起動確認

- ウインドウを表示しない起動確認（`SIGK_SMOKE=1 SIGK_SMOKE_HIDDEN=1`・`--user-data-dir=<scratchpad>`）で、幅 1,920・1,340・1,280・1,060・960 の
  ツールバーを撮り、1 列に収まり縮んでいないことを確かめる。
- 空のタブ: 閲覧・ページ編集・編集の各モードで「＋」→ 空のタブの画面、`SIGK_SMOKE_CLIPBOARD` の画像で Ctrl+V → 「新しい画像 1」のタブ、
  `SIGK_SMOKE_CLIPBOARD=empty` で通知バー。画面写真を `screenshots/new-tab-*.png` に残す。

## 手で確かめる筋書き（ユーザー）

1. 印刷画面を開き、プリンターの選択欄を開く。すべての項目が黒い文字で読める。
2. ツールバーの［開く］の右に、大きなアイコンと「印刷」の文字のボタンがある。ウインドウの幅を狭くしても、ツールバーが 1 列に収まる。
3. 編集モードで「＋」をクリックする。「新しいタブ」が開き、中央に［ファイルを開く］と案内文と最近使ったファイルが表示される。
4. Win＋Shift＋S などで画面の一部をコピーし、空のタブで Ctrl+V を押す。「新しい画像 1」のタブで画像が開き、書き込みができる。
5. ［上書き保存］を押すと、名前を付けて保存のダイアログが開き、ファイル名は「新しい画像 1.png」になっている。保存すると、タブ名が保存したファイル名になる。
6. 「＋」で空のタブを開き、［ファイルを開く］で PDF を選ぶ。空のタブの位置で PDF が開く。

### 実装で決めたこと（仕様書に無かった所。Claude の案）

1. Ctrl+V は `viewer-keys.js` の `handleKey` から受ける。確認画面を開いている間はどのキーも下の画面に渡さない決まりを、ほかのキーと同じ 1 か所で守るため。
2. 「＋」のツールチップから Ctrl+O を外した。Ctrl+O は空のタブを開かず、ダイアログを開くため（Ctrl+O は［ファイルを開く］のツールチップに書いた）。
3. 上限の判定（`isFull`）は、映している空のタブを数えない。開いたファイルのタブに置き換わるため。
4. 空のタブの画面は「文書が開かれていません」の文言欄を隠すので、開けなかった理由とドロップを断る理由は通知バーに表示する。
5. 空のタブの位置で読み込んでいる間は「読み込んでいます…」を表示する。
6. クリップボードの画像を組み立てられなかった時の通知文「クリップボードの画像を開けませんでした。」を追加した。大きすぎる時は、画像を開く時と同じ通知文。
7. 「新しい画像 N」の番号は、クリップボードの画像を読み込めた時に進める。読み込んでいる間の Ctrl+V は無視する。
8. 名前の無い画像の［上書き保存］のツールチップは「この画像は保存先が未指定なので、保存画面で保存先・名前・形式（PNG・JPEG・PDF）を指定してから保存します。」、
